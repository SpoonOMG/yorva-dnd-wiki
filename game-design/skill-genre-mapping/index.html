    docs/game-design/skill-genre-mapping.md — Рескин навыков по жанрам (canon → setting)¶

    Принцип (ADR-0008 гибрид рескина): механика НЕ меняется — skillId каноничен (код, броски d20+ability+prof), нарратив — displayName + flavor по world.genre. Детерминированный словарь skills.yml: label/description + settingReskin.yml (якоря) → fallback [Жанр] Канон → LLM JSON (800ms) → кэш.

    Источник истины: backend/app/src/main/resources/skills.yml (label: {fantasy, dark_fantasy, eastern, sci_fi, cyberpunk, post_apocalypse, horror, modern, western, ww2, steampunk, historical}) зеркалится в frontend/lib/skills.ts / activeSkills.ts и settingReskin.ts/.yml (детерминированные якоря). Механика — docs/game-design/skills-reference.md, проверки — CatalogService / TurnResolver.

    Канон жанров (worlds page + LootShowcaseService.LOOT_GENRES): fantasy (default), dark_fantasy, eastern, sci_fi (sci-fi), cyberpunk, post_apocalypse (post-apocalyptic), horror, modern, western, ww2, steampunk, historical, generic (fallback). SettingReskinService.normalizeSetting приводит sci-fi→sci_fi, post-apocalyptic→post_apocalypse.

    1. Пассивные навыки — 18 (STR/DEX/INT/WIS/CHA)¶

    Базовые описания (жанро-флейвор) — примеры; полный flavor в skills.yml/settingReskin.yml:

    • athletics: fantasy «Бег, прыжки, лазание, плавание» → cyberpunk «Прыжки по крышам неонового города, паркур», sci_fi «Маневр в невесомости, отталкивание», western «Родео, удержание в седле», ww2 «Марш с выкладкой 30кг»
    • arcana: fantasy «Знания о магии» → cyberpunk «Взлом нейросети, декодинг», sci_fi «Квантовые поля и аномалии», horror «Оккульт, ритуалы изгнания»
    • stealth: «Прятаться, красться» → cyberpunk «Оптический камуфляж, шумоподавление», post_apocalypse «Засада у развалин»
    • medicine: «Лечить, стабилизировать» → cyberpunk «Наношов, инъекция», western «Припарка шамана», ww2 «Жгут, сульфа»
    • survival: «Ориентирование, следы» → sci_fi «Навигация по экзопланете», western «Чтение прерии»

    Полная строка описания хранится как skills.yml: description (канон) + жанровый flavor в рескине: напр. skills.yml: athletics.description канон, а label.cyberpunk flavor = "Прыжки по крышам".

    3. Инварианты и фолбэки¶

    • canonicalId не меняется — баланс/проверки по нему (TurnResolver, CatalogService, SessionService.proficiencies).
    • label[setting] приоритет: skills.yml label[normalizedSetting] → settingReskin.yml детерминированный якорь → [Жанр] Канон префикс → LLM JSON {displayName, flavor} (800ms) → кэш SettingReskinService.cache.
    • Нормализация: sci-fi/sci_fi/scifi → sci_fi, post-apocalyptic/post_apocalypse → post_apocalypse, dark fantasy → dark_fantasy, киберпанк→cyberpunk и т.д. (см. SettingReskinService.settingLabel + LootShowcaseService.normalizeGenre).
    • Frontend зеркало: lib/skills.ts SKILL_GENRE_NAMES + activeSkills.ts ACTIVE_SKILL_GENRE_NAMES + lib/settingReskin.ts MAP — тот же словарь, что в skills.yml/settingReskin.yml; кэш Map.
    • API: GET /api/skills?setting=cyberpunk (новый) + существующие GET /api/spells?setting, GET /api/classes?setting, GET /api/subclasses?setting — все через SettingReskinService.reskin.
    • Тесты: component reskin.feature — детерминированные якоря (GET /api/spells/fireball?setting=cyberpunk → Термозаряд), фолбэк стеампанк префикс; расширить на GET /api/skills?setting=sci_fi и .../active.

    4. Синхронизация¶

    • backend/app/src/main/resources/skills.yml — полный label 12 жанров для 37 ид
    • backend/app/src/main/resources/settingReskin.yml — 60→ ~120 якорей (top-10 заклинаний + 12 классов + 6 подклассов + 37 скиллов × 3 якоря = демо, остальное через skills.yml)
    • frontend/lib/skills.ts — SKILL_GENRE_NAMES: Record<SkillId, Record<Genre,string>> + getSkillDisplayName(id, genre)
    • frontend/lib/activeSkills.ts — аналогично ACTIVE_SKILL_GENRE_NAMES
    • frontend/lib/settingReskin.ts — MAP расширен до 37×3 якорей (проверка детерминизма), фолбэк префикс
    • frontend/lib/theme.ts — GENRE_ALIASES уже покрывает sci-fi/cyberpunk/horror, добавить dark_fantasy/eastern/post_apocalypse/western/ww2/modern/steampunk/historical
    • api-specification/openapi.yaml — GET /api/skills + SkillDto (id, name, ability, description, flavor, setting)
