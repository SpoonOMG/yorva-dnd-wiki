    2. Фиксированные владения по классам (детерминированно, без UI выбора)¶

    Выбираем каноничные 2-4 из SRD-списка, чтобы каждый из 18 покрыт хотя бы одним классом, и распределение сбалансировано.

    Класс SRD choose Фиксировано proficiencies.skills (classes.yml) Покрытие
    warrior (Fighter) 2 из 8: Acrobatics, Animal Handling, Athletics, History, Insight, Intimidation, Perception, Survival ATHLETICS, PERCEPTION STR+WIS
    barbarian 2 из 6: Animal Handling, Athletics, Intimidation, Nature, Perception, Survival ATHLETICS, SURVIVAL STR+WIS
    bard 3 любых PERFORMANCE, PERSUASION, PERCEPTION CHA+WIS
    cleric 2 из 5: History, Insight, Medicine, Persuasion, Religion INSIGHT, RELIGION WIS+INT
    druid 2 из 8: Arcana, Animal Handling, Insight, Medicine, Nature, Perception, Religion, Survival NATURE, SURVIVAL INT+WIS
    monk 2 из 6: Acrobatics, Athletics, History, Insight, Religion, Stealth ACROBATICS, STEALTH DEX
    paladin 2 из 6: Athletics, Insight, Intimidation, Medicine, Persuasion, Religion INSIGHT, PERSUASION WIS+CHA
    ranger 3 из 8: Animal Handling, Athletics, Insight, Investigation, Nature, Perception, Stealth, Survival PERCEPTION, STEALTH, SURVIVAL WIS+DEX
    rogue 4 из 11: Acrobatics, Athletics, Deception, Insight, Intimidation, Investigation, Perception, Performance, Persuasion, Sleight of Hand, Stealth STEALTH, SLEIGHT_OF_HAND, DECEPTION, PERCEPTION DEX+CHA+WIS
    sorcerer 2 из 6: Arcana, Deception, Insight, Intimidation, Persuasion, Religion ARCANA, DECEPTION INT+CHA
    warlock 2 из 7: Arcana, Deception, History, Intimidation, Investigation, Nature, Religion ARCANA, INTIMIDATION INT+CHA
    wizard 2 из 6: Arcana, History, Insight, Investigation, Medicine, Religion ARCANA, HISTORY INT

    Проверка покрытия: все 18 встречаются хотя бы в одном классе. Дублирование допустимо (Perception у 5 классов — как в SRD).

    sneak_attack DEX 1 rogue +1d6 при advantage
    cunning_action DEX 2 rogue Бонус: Скрыться/Отход/Рывок
    rage STR 1 barbarian +2 урон, resist физ, 1/отдых
    bardic_inspiration CHA 1 bard Кость 1d6 союзнику
    wild_shape WIS 2 druid Облик зверя
    ki DEX 2 monk Ки-очки, Flurry
    divine_channel WIS 1 cleric Изгнание нежити
    lay_on_hands CHA 1 paladin 5×уровень HP исцеление
    hunters_mark WIS 1 ranger Метка +1d6
    arcane_recovery INT 1 wizard 1/день слоты
    sorcery_points CHA 2 sorcerer Метамагия
    pact_magic CHA 1 warlock Слоты на short rest
    power_strike STR 1 warrior, barbarian, paladin Атака + урон, оглушить
    shield_bash STR 1 warrior, paladin Бонус: помеха цели
    double_shot DEX 2 ranger 2× атака с помехой
    help_action CHA 1 all Advantage союзнику

    Механика: пассивные — d20 + attrMod + proficiencyBonus(level) если proficient, активные — ActionType + StateChange в TurnResolver/SessionService.

    4. Синхронизация файлов¶

    • backend/app/src/main/resources/skills.yml — classes из колонки SRD (полный список, не фиксированный)
    • backend/app/src/main/resources/classes.yml — proficiencies.skills из колонки Фиксировано
    • backend/app/src/main/kotlin/com/yorva/classes/ClassRegistry.kt fallback — те же фиксированные
    • frontend/lib/skills.ts — 18 SKILLS + поле classes для фильтра (опционально)
    • frontend/lib/skillIcons.ts — иконки для 18 + активных
    • frontend/components/game/ActiveSkillsPanel.tsx — фильтр по canonicalClassId
