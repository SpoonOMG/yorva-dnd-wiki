    Витрина лута (loot showcase)¶

    Статус: согласовано с продуктом (2026-09-02), к реализации.

    Проблема¶

    Текущий путь выдачи предметов: LLM придумывает предмет тегом [GRANT_ITEM], движок пытается сматчить архетип из маленького справочника. Промах матчинга = предмет с нулевыми статами и без иконки (наблюдалось на проде: «гидромонтажный рычаг»). Прогрессии нет: нарратив отдаёт что угодно, справочник не растёт с уровнем персонажа.

    Принцип¶

    Экономика и баланс — детерминированный движок; драматургия — LLM. Движок по RNG формирует «витрину» из 3 предметов справочника, LLM выбирает один (или ни одного) и обыгрывает его в нарративе. LLM не придумывает обычный лут — только выбирает из детерминированных вариантов.

    Справочник предметов¶

    Объём: 3500 предметов = 10 жанров × 10 уровней × 35 предметов.

    Категория На уровень Назначение
    Оружие 20 урон
    Броня 10 защита (AC)
    Расходники 5 зелья и пр., выдача по 1 шт.

    Генерация — LLM-скриптом (офлайн), человеческая вычитка. LLM-генератор создаёт только: имя, описание, категорию, редкость, уровень, тег иконки. Статы LLM не задаёт.

    Иконки¶

    Иконотека уже существует: frontend/public/icons/items/ — 150 иконок (game-icons.net, CC BY 3.0) с манифестом ключей (sword-basic, laser-katana, …). При генерации справочника LLM-скрипт выбирает icon_key каждого предмета из фиксированного списка ключей манифеста (передаётся в промпт целиком). Скрипт-валидатор проверяет существование каждого ключа; невалидный → дефолт категории (sword-basic и т.п.). Рантайм-матчинга нет — иконка детерминированно записана в справочнике. Повторы иконок между предметами допустимы (иконка обозначает тип, не уникальность); расширение библиотеки — отдельная задача.

    10 жанров-справочников: фэнтези, тёмное фэнтези, sci-fi, киберпанк, постапокалипсис, хоррор, стимпанк, вестерн, исторический/античность, generic (fallback).

    Статы предмета¶

    Детерминированно из «уровень × редкость × категория» по таблице силы, умноженные на случайный коэффициент 0.9–1.2. Коэффициент фиксируется при генерации предмета (сид от ID предмета) — статы одного предмета не плавают между показами.

    Базовая таблица силы (урон оружия; броня/расходники — по аналогичной шкале):

    Редкость Урон
    COMMON 1d6
    UNCOMMON 1d8
    RARE 1d10+1
    EPIC 2d6+2
    LEGENDARY 2d8+3

    Точные значения по уровням выверяются при реализации таблицы.

    Дополнительные свойства (rare+) — отложено¶

    Свойства, влияющие на механику (напр. «+1d4 огнём», «преимущество на скрытность»), берутся в работу вместе с проработкой противников (элита/боссы). В модели данных предмета сразу закладывается поле properties[] (пустое в v1), чтобы не ломать совместимость.

    Выбор справочника для мира¶

    При старте сессии LLM получает список 10 жанров-справочников и в ответном сообщении указывает ключ наиболее релевантного справочника (по контексту мира). Движок сохраняет ключ в сессии. Если LLM не ответила или ответила мусором — fallback: world.genre → generic.

    Витрина¶

    • Размер: 3 предмета, уровень = текущий уровень персонажа.
    • RNG по кривой редкости (см. ниже), дедуп внутри сессии: предметы, уже выданные игроку, исключаются из RNG.
    • LLM выбирает 1 из 3 или ни одного; выбор обыгрывается нарративом.
    • Игрок витрину не видит — чистый нарратив, витрина внутренняя кухня движка.

    Кривая редкости по уровню персонажа¶

    Уровень COMMON UNCOMMON RARE EPIC LEGENDARY
    1 90% 10% — — —
    2 70% 20% 10% — —
    3 40% 30% 20% 10% —
    4-5 уточняется при реализации (плавный сдвиг к rare/epic) —
    6+ … … … … 1-2%

    Ограничения: LEGENDARY — не более 1 за сессию (контролирует движок). Противники повышенной сложности (элита/боссы) с повышенными шансами — отдельной задачей при проработке противников.

    Триггеры витрины¶

    Триггер Поведение
    Старт сессии Всегда витрина 1 уровня (в ближайших ходах игрок находит первое оружие)
    Победа в бою Шанс 30-50%
    Контейнер / «обыскиваю» Шанс (уточняется при реализации)
    Награда за квест Гарантированно
    Тег [REQUEST_LOOT] от LLM По запросу в сюжетных точках

    Сюжетно-уникальные предметы (GRANT_UNIQUE)¶

    Параллельный путь для уникальных предметов («отцовский арбалет»), которых нет в справочнике. LLM помечает их отдельным тегом [GRANT_UNIQUE:…]. Если архетип не найден — статы берутся из таблицы «категория × редкость» × коэффициент 0.9–1.2, имя/описание остаются от LLM. Гейт упоминания предмета в сцене сохраняется (защита от выдачи «из воздуха»).

    Итог: витрина — основной путь (~95% лута, детерминированные статы и прогрессия), GRANT_UNIQUE — исключение для сюжета, всегда с рабочими статами.

    Не входит в v1¶

    • Дополнительные свойства rare+ (с фазой противников).
    • Повышенные шансы лута у элиты/боссов (с фазой противников).
    • Еженедельная перегенерация названий предметов шедулером («на подумать», чтобы названия не приедались аудитории).
