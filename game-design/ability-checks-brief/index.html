    Бриф: каталог проверок характеристик для всех действий (seed БД)¶

    Статус: бриф для миграции 0015-action-catalog (покрывает B-11, B-12, B-15, B-18, B-19 + внешние ГМ #1-7, седтари sci-fi/ориентал).
    Цель: заменить regex-эвристику TurnResolver.kt на иерархический справочник — источник правды для движка. Любое действие игрока маппится на запись каталога → движок берёт attribute/skill/dc/damage_stat без угадывания LLM. Непокрытые кейсы — через LLM-классификатор в ближайшую категорию + clamp, никогда null.

    1. Принцип работы (трёхуровневый матчинг)¶

    1. CatalogService.findMatch(actionLower) ищет токены с учётом русской морфологии: (?U)\bkeyword\w*\b (суффиксы: меч→мечом/мечи, стрела→стрелу/стрелы), длинный токен приоритетнее короткого (световой меч > меч), приоритет weapon > spell_family > skill_check (чтобы «хлыст» как оружие не съел заклинание «хлыст тени» — см. дизамбигацию).
    2. Нашли точное оружие/заклинание → resolveAttack(weapon) / resolveSpell(family).
    3. Не нашли → CatalogClassifier (маленький LLM, temp 0) → возвращает только category_key из закрытого списка (ровно 7 оружейных категорий + 4 магических семейства, §2.1/§3). Категории — исчерпывающие по мета-типам.
    4. Даже если классификатор упал → default_weapon (1d4 + strMod) / default_spell (1d6 + intMod, save wis DC13) + лог unknown_action. Бой никогда не ломается.

    DB — seed, read-only на MVP (UNIQUE(key)), расширяется без кода через weapon_traits/effect_templates. Токен лук\b без \w* дал бы пропуск луки/лука и ложное лук (овощ) → используем \w* + стоп-контекст нарезать лук игнорируется если рядом нет боевого глагола (стрелять/атаковать).

    2. Оружие — иерархия категорий → экземпляры + трейты¶

    2.1 Категории (закрытый список — 7 оружейных + 4 магических семейства)¶

    Оружейные — ровно 7 weapon_categories (для CatalogClassifier):

    category_key name_ru attack_stat_default damage_dice_default примеры ключевых слов clamp is_finesse_default
    kinetic_melee Холодное ближнее str 1d8 меч\w, топор\w, булава\w, посох\w max 2d6 false
    kinetic_ranged Кинетическое дальнее dex 1d8 лук\w, арбалет\w, ружьё\w, винтовк\w, автомат\w, дробовик\w, калаш\w* max 2d6, burst 2d6 false
    energy Энергетическое dex (psionic→int) 1d8 бластер\w, лазер\w, плазм\w, световой меч\w max 2d6 false
    oriental Японское (подтип kinetic_melee) dex/str finesse 1d8 катана\w, вакидзаси\w, танто\w, нагината\w max 2d6 true
    throwable Метательное str 1d6 дротик\w, сюрикен\w throw 10м false
    finesse_melee Фехтовальное max(str,dex) 1d6 кинжал\w, нож\w, рапира\w* light true
    unarmed Без оружия str 1 кулак\w, пинок\w — false

    3 мета-группы покрывают всё: kinetic_melee (включая oriental/finesse как подтипы), kinetic_ranged, energy — любой новый «плазменный кукри» → kinetic_melee. oriental/finesse_melee — не новые мета-типы, а подкатегории с is_finesse=true для правила max(str,dex).

    Магические семейства — ровно 4 (см. §3): direct_damage / save_debuff / control / summon_heal_buff.

    rifle Винтовка kinetic_ranged 1d10 dex ammo, heavy винтовк\w, ружьё\w, ружье\w*

    Формула: hit = d20 + attack_stat_mod (+prof) >= ac; damage = damage_dice + damage_stat_mod (крит ×2 кубика, B-18, B-19).

    2.3 Трейты оружия (компонуемые)¶

    weapon_traits(key, name_ru, extra_dice, damage_type, status, save_stat, save_dc, keywords, max_stacks, duration_rounds)

    key extra_dice эффект save duration keywords
    flaming +1d6 fire Горение 3 раунда, tick 1d6/ход — 3, tick 1d6 огнен\w, пламен\w, fire\w*
    frost +1d6 cold Замедлен 2 раунда dex 13 2 мороз\w, холод\w, frost\w*
    poisoned +1d4 poison Отравлен (помеха) con 13 до отдыха ядовит\w, отрав\w, poison\w*
    cursed +1d4 necrotic Проклятие слабости (-2 STR) до remove_curse wis 14 indefinite проклят\w, cursed\w
    vampiric — хил ½ урона — instant вампир\w*
    keen — крит 19-20 — passive заточ\w, keen\w

    Композиция: dagger 1d4 + poisoned 1d4 + flaming 1d6 + mod = 1d4+1d4+1d6+mod мгновенно + 1d6/ход ×3 тиков. Clamp включает DoT: sum(extra_dice) + sum(tick_dice × duration) ≤ 3d6 эквивалента — иначе обрезаем тики. ≤2 трейта, max_stacks=1 (ре-апплай сбрасывает remaining_rounds, не стакается). Приоритет: трейт ищется после базы оружия, длинный токен первым.*

    family_key name_ru attack_type caster_stat save_stat mana_cost default_damage keywords
    direct_damage Прямой урон spell_attack int — 3 1d8 огненная стрела, молния, тень
    save_debuff Урон + дебаф save int/cha con/wis 3-4 2d4 яд, проклятие, хлыст, чума
    control Контроль save wis/cha wis 4 — удержание, страх, паралич
    summon_heal_buff Призыв/хил auto/summon wis/int — 2-5 heal 1d6 призыв, лечение, щит, невидимость

    Любое новое «теневой хлыст» → классификатор → save_debuff, save=wis, 2d4, status=poison — без новой записи. Потолок 3d6.

    Правила: spell_attack: d20+mod vs AC, save: DC=8+mod+prof vs d20+save_mod, auto_hit: 1d4+1.

    7. Правила движка (для кода)¶

    • AC: 10 + dexMod (без доспеха) — фиксит GameState.kt:189 ac >=0; ранее было 10 хардкожено.
    • Инициатива: d20 + dexMod при спавне врага.
    • Крит/фамбл: 20 → автохит ×2 кубика, 1 → автопромах + Ошеломлён.
    • Попадание: total >= ac (B-19) строго >= — 10 vs AC10 = хит (было непоследовательно).
    • Урон: dice + statMod (B-18), отображение 1d8+2 = 6 (4+2), clamp включая DoT: sum(extra)+sum(tick×rounds) ≤ 3d6 эквивалента.
    • Смерть (B-17): GameState.kt:185 hp in 0..maxHp → HP клипается в 0, критерий hp == 0 (не ≤0). Если hp==0 → status=Без сознания; в обычном режиме — спасброски d20 каждый ход: 10+ успех, <10 провал, 1=2 провала, 20=1 HP и сознание; 3 провала → isDead=true; в хардкоре MechanicsProfile.permadeath=true → сразу isDead. Стоп контратак при Без сознания.
    • Длительные эффекты: active_effects[] (key, remaining_rounds, duration_type[rounds/indefinite/condition], stacks, max_stacks=1) — ре-апплай сбрасывает remaining, не стакается; каждый ход тик damage + save( wis/con DC); LLM получает Активные эффекты: Горение 2/3 (1d6). B-13: при enemy != null промпт запрещает выдумывать поляну, B-16: повтор set_trap когда active_effects уже есть → no_roll «ловушка уже стоит».
    • DC с учётом сложности: effective = base + dcOffset (easy -2, normal 0, hardcore +3).
    • Помеха: hp < max/2 или Отравлен → помеха к атакам/ловкости.

    8. Формат seed для БД (Liquibase 0015 — закрывает замечания ревью)¶

    - changeSet: { id: 0015-categories, createTable: weapon_categories(key, name_ru, attack_stat_default, damage_dice_default, is_finesse_default bool, clamp_max_dice) }
- changeSet: { id: 0015-weapons, createTable: weapons(key, category FK, name_ru, damage_dice, damage_stat, is_finesse bool, properties JSON, keywords) } # properties: {versatile:"1d10", throw:"6м", ammo:"45м", burst:true}
- changeSet: { id: 0015-traits, createTable: weapon_traits(key, name_ru, extra_dice, damage_type, status, save_stat, save_dc, duration_rounds, duration_type[rounds/indefinite], max_stacks int, keywords) }
- changeSet: { id: 0015-effects, createTable: effect_templates(key, name_ru, type[dot/buff/debuff], duration_rounds int, duration_type[rounds/indefinite/condition], tick_dice, save_stat, save_dc, keywords) } # duration_type покрывает "до отдыха"/"до remove_curse"
- changeSet: { id: 0015-spell-families, createTable: spell_families(key, name_ru, attack_type[spell_attack/save/auto], caster_stat, save_stat, mana_cost, default_damage, keywords) }
- changeSet: { id: 0015-skill-checks, createTable: skill_checks(key, name_ru, attribute, skill, dc_easy, dc_medium, dc_hard, keywords) }
- changeSet: { id: 0015-active-state, addColumn: sessions(active_effects_json JSONB), turns(active_effects_snapshot JSONB) }

    JSON пример: 

    {"category":"energy","key":"blaster","damage_dice":"1d8","attack_stat":"dex","is_finesse":false,"keywords":["бластер\\w*","плазм\\w*"]}
{"trait":"flaming","extra_dice":"1d6","status":"burning","duration_rounds":3,"duration_type":"rounds","max_stacks":1,"keywords":["огнен\\w*","пламен\\w*"]}
{"effect":"burning","type":"dot","duration_rounds":3,"duration_type":"rounds","tick_dice":"1d6","save_stat":"wis","save_dc":13}
{"spell_family":"save_debuff","attack_type":"save","caster_stat":"int","save_stat":"con","mana_cost":3,"keywords":["яд\\w*","прокляти\\w*","хлыст\\w*"]}

    Каталог — единственный источник attack_stat/dc/skill; классификатор — только выбор категории из списка.
