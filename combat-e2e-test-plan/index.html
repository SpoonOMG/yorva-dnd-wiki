    Тест-план e2e-кампании: боевые механики (autoplayer)¶

    Дата: 2026-10-28. Инструмент: tools/e2e-player/ (runner + LLM-автоигрок + debug-хуки). Прогон: каждый кейс ×3 итерации (ротация стилей автоигрока: осторожный тактик / импульсивный авантюрист / внимательный исследователь), классы персонажей ротируются.

    Уже покрыто существующими сценариями (НЕ дублировать)¶

    • combat_attack_roll, combat_enemy_counterattack, combat_kill_xp_loot, combat_typed_damage — базовый цикл боя.
    • maneuver_battle_master_trip, maneuver_precision_attack, maneuver_riposte, maneuver_riposte_absent, maneuver_shove_prone — манёвры Battle Master и базовый shove.
    • death_saves, monster_llm_spawn, monster_skeleton_resist — смерт. спасброски, спавн, резисты скелета.
    • ability_* (rage/ki/lay_on_hands/second_wind/bardic), channel_divinity_cleric, wildshape_druid, spell_*, rest_* — фичи и заклинания.

    Эти сценарии входят в финальный регресс, но в новую кампанию не добавляются.

    Общие паттерны сценариев¶

    • Смертельные бои: топ-ап HP через hook set_state {hp: ...} после атак, чтобы игрок не умер до достижения DoD.
    • Оружие: hook drop_item {name, category} → «подбираю X» → «экипирую X» (подбор в бою провоцирует контратаку — топ-апы покрывают).
    • Финальный DoD НЕ полагаться на enemy absent (нарратор доспавнивает врага после килла). Использовать dod.turns (mechanics.* конкретного хода) и state-проверки (xp↑, инвентарь).
    • Текстовые DoD (contains_substr по description) хрупки — предпочитать mechanics.action, diceRolls[*].reason, state-пути.
    • Триггерные слова (semantic-dictionary.yml): dodge — «уклоняюсь», disengage — «отступаю», dash — «рывок», hide — «прячусь», ambush — «затаиться/засада». ENV_SHOVE_VERB+ENV_HAZARD_NOUN (TurnResolver.kt:4394/4396): «толкаю врага в пропасть/огонь/шипы».
    • Монстры: см. monsters.yml (20 statblock'ов). kobold — str 7 (легко толкать/грапплить), orc — str 16 (трудно), skeleton — vuln bludgeoning, zombie — низкий AC 8, ogre — танк 59 hp, bugbear — мультиатака.

    Группа A. Базовые атаки и оружие (6 кейсов)¶

    ID Кейс Класс Суть DoD (основное)
    A-01 Атака мечом после экипировки warrior drop_item меч → подобрать → экипировать → атака; урон больше безоружного turns: diceRolls reason «Атака», mechanics.enemyDamage > 0
    A-02 Дальнобойная атака из лука ranger экип лука → «стреляю во врага из лука» turns: description/attack с дальнобойным уроном, enemyDamage > 0
    A-03 Безоружная атака (пинок) monk «пинаю врага» / «бью кулаком» без оружия turns: mechanics.action=ATTACK, урон ≥1
    A-04 Мультиатака воина L5 (Extra Attack) warrior L5 (levelup) «атакую дважды» или две атаки подряд в бою turns: ≥2 броска атаки игрока в одном ходу (extra attack strikes)
    A-05 Критическое попадание/промах обрабатываются barbarian серия атак до первого крита (d20=20/1 встречается за N ходов) turns: description содержит «Критическ» хотя бы раз за 15 ходов (мягкий DoD — иначе FLAKY: тогда кейс-наблюдение без жёсткого DoD)
    A-06 Типизированный урон булавой по скелету (уязвимость) cleric экип булавы → атака скелета → урон ×2 (vuln bludgeoning) turns: enemyDamage ≥ 2×базового куба при попадании (проверка по description «уязвим»/удвоению)

    Группа B. Action economy: защитные действия (6 кейсов)¶

    ID Кейс Класс Суть DoD
    B-01 Уклонение (Dodge) warrior «уклоняюсь» → ответ врага с помехой turns: mechanics.action=DODGE; следующий ход: атака врага промах (enemy_missed=true)
    B-02 Отступление (Disengage) без провокации rogue «отступаю» в бою turns: mechanics.action=DISENGAGE; в тот же ход нет opportunity-атаки по игроку
    B-03 Рывок (Dash) и сброс dashUsedThisTurn ranger «рывок» два хода подряд — оба должны пройти (регресс на ранее найденный баг не-сброса флага) turns: два хода с mechanics.action=DASH без отказа
    B-04 Скрытность → скрытая атака с преимуществом rogue «прячусь» → следующий ход «атакую из укрытия» turns: hide-ход с action=HIDE; атака после hide — description про преимущество/скрытую атаку
    B-05 Дублирование основного действия запрещено warrior две явные атаки в одном сообщении / атака после атаки с action economy turns: отказ «Основное действие уже использовано» (или аналог) — state HP игрока unchanged
    B-06 Бонус-действие после основного в одном ходу warrior «атакую и использую Второе дыхание» в одном сообщении turns: оба эффекта применены (урон врагу + хил игрока)

    Группа C. Манёвры-контесты и окружение (6 кейсов)¶

    ID Кейс Класс Суть DoD
    C-01 Захват (grapple) → RESTRAINED barbarian (str 16) vs kobold (str 7) «хватаю врага» / «захватываю гоблина» turns: diceRolls reason «(contested)», при успехе description про захват/RESTRAINED
    C-02 Толчок против сильного врага (провал) wizard (str 8) vs orc (str 16) «толкаю врага» — чаще провал turns: contested roll присутствует; допустим любой исход, но текст исхода соответствует броску (кейс-консистентности)
    C-03 Толчок в пропасть (env-shove) warrior spawn commoner → «толкаю врага в пропасть» turns: ENV_SHOVE (урон max(maxHp/2,3) врагу); description про пропасть/падение
    C-04 Толчок в огонь/шипы (env-shove, хазард) barbarian «сдвигаю врага в огонь», «заталкиваю врага в шипы» turns: урон врагу от env-shove; разные хазард-слова распознаются
    C-05 Env-shove добивает врага → XP + лут warrior враг с low hp (через серию атак) → «сталкиваю врага в пропасть» state: xp increased_from_setup; turns: килл env-shove'ом
    C-06 Обезоруживание (disarm) warrior (battle master не нужен) «выбиваю оружие у врага» turns: contested/disarm-путь; либо явный отказ, если механика не реализована (кейс-разведка: зафиксировать поведение)

    Группа D. Объекты и опасности в бою (5 кейсов)¶

    ID Кейс Класс Суть DoD
    D-01 Бросок предмета во врага warrior drop_item (камень/факел) → «бросаю факел во врага» turns: урон врагу или USE/OBJECT action с целью ENEMY
    D-02 Разрушение объекта в бою (ящик с лутом) barbarian «ломаю ящик» в бою → лут из контейнера state: inventory ↑ после подбора; turns: OBJECT break
    D-03 Преодоление опасности (яма с шипами) monk «прыгаю через яму с шипами» в бою turns: HAZARD/CHECK (акробатика) — при провале урон игроку
    D-04 Зелье лечения в бою cleric drop_item зелье → «выпиваю зелье» в бою state: hp increased; turns: action economy соблюдена (атака после зелья в тот же ход отклонена)
    D-05 Экстинкция/взаимодействие с огнём (тушу факел) druid «тушу факел» / «заливаю огонь водой» turns: OBJECT-экстинкция или осмысленный нарратив без падения движка

    Группа E. Реакции (6 кейсов)¶

    ID Кейс Класс Суть DoD
    E-01 Реакция «Щит» предлагается при попадании по визарду wizard (знает shield) враг попадает → в ответе/состоянии доступна реакция SHIELD turns/state: availableReactions содержит SHIELD при PLAYER_TAKES_DAMAGE
    E-02 Применение реакции «Щит» wizard после предложения — «использую реакцию щит» turns: +5 AC применён, слот потрачен
    E-03 Uncanny Dodge плута L5 rogue L5 (levelup) враг попадает → предложение «Невероятное уклонение» turns/state: реакция предложена; при принятии урон уполовинен
    E-04 Hellish Rebuke тифлинга warlock (tiefling, знает hellish_rebuke) враг попадает → реакция огнём по атакующему turns: урон врагу от реакции (enemyDamage без атаки игрока)
    E-05 Реакция не предлагается без ресурса warrior L1 враг попадает → никаких реакций нет state: availableReactions пуст
    E-06 Реакция тратится один раз за раунд wizard (shield) две подряд реакции → вторая отклонена turns: отказ про уже потраченную реакцию

    Группа F. Особые механики (6 кейсов)¶

    ID Кейс Класс Суть DoD
    F-01 Добивание (Finishing Blow) warrior враг на low hp → «добиваю врага» turns: FINISHING_BLOW → килл; state: xp ↑
    F-02 Подготовка засады (ambush_prep) ranger «затаиться и ждать в засаде» turns: action=ambush_prep, эффект засады в description
    F-03 Дыхание драконорождённого в бою dragonborn warrior «использую огненное дыхание» turns: урон врагу от дыхания; defeated → withLoot
    F-04 Дыхание добивает врага dragonborn barbarian враг low hp → дыхание → килл state: xp ↑, лут в droppedItems
    F-05 Ярость + атака в одном бою (комбо) barbarian «впадаю в ярость» → атаки с бонусом ярости turns: урон атаки вырос на +2 после ярости
    F-06 Инициатива: враг ходит первым (pre-strike) wizard (dex низкий) spawn scout (dex высокий) → враг наносит урон до первого хода игрока turns[0]: урон игроку до первой атаки игрока

    Группа G. Сквозные цепочки (4 кейса)¶

    ID Кейс Класс Суть DoD
    G-01 Затяжной бой vs bugbear с топ-апами warrior победа над bugbear (27 hp, мультиатака) state: xp ↑ на 200; turns: несколько раундов, контратаки врага
    G-02 Два врага последовательно paladin kill первого → hook spawn второго → kill state: xp ↑ дважды
    G-03 Игрок падает до 0 HP в бою и поднимается хилом cleric враг доводит до 0 → death save → союзный хил/самохил после стабилизации state: hp > 0 в конце; turns: death saves видны
    G-04 Полный цикл: бой → лут → экип → второй бой warrior kill → подбор оружия с трупа → экип → spawn нового врага → kill с новым оружием state: инвентарь содержит оружие, xp ↑ дважды

    Итого¶

    39 новых кейсов (A-01…G-04) × 3 итерации = 117 прогонов. Классы: warrior, ranger, monk, barbarian, cleric, rogue, wizard, druid, paladin, warlock — ротация по кейсам. Стили автоигрока ротирует runner.

    Критерии вердиктов¶

    • PASS — все DoD выполнены.
    • FLAKY — нестабильный кейс (рандом d20, LLM-вариативность): допустимо, но фиксируется и по возможности переписывается на детерминированный DoD.
    • FAIL — кандидат в дефект: разбор через jsonl (brief_mechanics) + живой прогон через client.py для полного mechanics. Решение «дефект движка vs правка сценария» — по коду (TurnResolver.kt и др.).
