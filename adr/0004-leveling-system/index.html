    ADR 0004 — Система прокачки (leveling) детерминированная, расширяемая под подклассы/мультикласс¶

    Дата: 2026-09-08 Статус: Принято (фаза 1 — без подклассов/мультикласса, задел под них)

    Контекст¶

    До 0fe54b4 персонаж создавался L1 и рос только через HP/XP без PB/фич/ASI/слотов — CharacterState.level/xp и pendingASI были заглушками. Нужна каноничная SRD 5.1 прокачка 1-20 для 12 классов, детерминированная (часы-механика ADR-0003), с одним выбором игрока на ASI ур. (4,8,12,16,19, у warrior +6, у rogue +10) и слотами заклинаний. Подклассы (sacred oath паладина на 3) и мультикласс — следующая итерация, но архитектура должна их принять без миграции данных.

    Решение¶

    • Таблица уровня — level-table.yml xp -> level SRD [0,300,900,2700,6500,14000,23000,34000,48000,64000,85000,100000,120000,140000,165000,195000,225000,265000,305000,355000] + PB +2..+6 (1-4:+2,5-8:+3,9-12:+4,13-16:+5,17-20:+6). Источник истины — файл, не код.
    • Классы — classes.yml расширяется: hitDie, asiLevels:[4,8,12,16,19] (+ доп.), spellSlotsTable[1..20][1..9], features[level], savingThrows уже есть. Без subclass пока — поле subclassId: null в CharacterState + subclasses.yml заглушка.
    • Фиты — feats.yml 42 SRD, MVP 12 с prerequisite и repeatable:false, кап хар-ки 20, сумма ASI = 2 (+2 или +1+1).
    • HP — детерминированно средним d6=4,d8=5,d10=6,d12=7 + CONmod, L1 = max+CON, далее avg+CON. Без броска — реплей.
    • Движок — LevelUpService чистый: canLevelUp(xp), levelUp(state, asiChoice?) -> state, preview(state) -> LevelUpPreview. Без LLM, один StateChange.GainXp триггерит. multiclass — поле classes: List<ClassLevel>{classId, level} в CharacterState (пока size=1), totalLevel = sum(levels) для PB/xp.
    • API — GET /level-table, GET /feats, POST /sessions/{id}/levelup {asiChoice|featId|spellChoices} GET /levelup/preview — spec-first openapi.yaml.
    • Фронт — LevelUpModal как SpellCard (чипы PB/HP/фича, выбор ASI/фит, выбор заклинаний known/prepared).

    Последствия¶

    • Про: 1-20 канон, PHB ASI 4,8,12,16,19 + warrior 6/rogue 10/14 уже заложены, подкласс добавится subclassId + features[3,6,11,14] без миграции, мультикласс — classes[] и pbFor(totalLevel). Тесты level-up.feature детерминированы.
    • Конс: feats 42 + 12×20 фич — большой classes.yml (~800 строк), требует SpellSlots.forLevel переписать под таблицу класса (не только full caster).

    Альтернатива¶

    XP на бэке рандом/HP броском — ломает реплей ADR-0003. Отложили subclass в classes.yml вложенно — выбрали отдельный subclasses.yml для расширяемости.
