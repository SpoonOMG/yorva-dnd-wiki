    ADR-0033: Class Feature Mechanics II — Channel Divinity / Wild Shape / Metamagic (3.7c)¶

    Status¶

    Accepted

    Context¶

    ФАЗА 3.7a/3.7b дала EffectSpec-механику фичам воина/плута/монаха (ADR-0029/0030/0031). Остаются три «дорогие» механики из devlog 151/152: Channel Divinity (cleric), Wild Shape (druid), Metamagic (sorcerer). Инфраструктура (ресурсы, activatable, choice-фичи, EffectSpec) есть; механики нет.

    Факты (файл:строка):

    # Файл:строка Факт
    1 classes.yml:440-449,487 Cleric L2 «Божественный канал»: ACTION, CHANNEL_DIVINITY (table:2=1,6=2,18=3, ShortRest). effect:/choice: нет. Turn Undead в данных отсутствует.
    2 GameState.kt:743-792 + changes/0036-creature-archetypes.yaml У Enemy и creature_archetypes нет creature type — undead-гейт Turn Undead невозможен без ФАЗЫ 4.
    3 conditions/StatusId.kt TURNED отсутствует; флаговая модель (ACT/ATTACK/MOVE_BLOCKERS) — готовая точка расширения.
    4 classes.yml:748-755,775 Druid L2 «Дикий облик»: ACTION, WILD_SHAPE (table:2=2, ShortRest). effect: нет.
    5 (grep tempHp\|temporaryHp = 0) Ни отдельного HP-пула формы, ни temp HP в движке нет. Bestiary/данных зверей нет.
    6 classes.yml:1195-1223,1237 Sorcerer L2 «Очки чар» (SORCERY_POINTS, maxFormula: level, LongRest); L3 «Метамагия» — задел без choice:-блока.
    7 rules/choice/ClassChoice.kt:77-81 + ClassChoiceMapper.kt:34 MetamagicChoice существует, маппинг по имени «Метамагия» — есть; данных нет → не активен. Применение выборов → l1Choices (прецедент манёвров).
    8 SpellService.kt:56-105 + TurnResolver.kt:1985-2053 canCast/castSpell(spell, caster, targets, combatState, upcastLevel); модификаций кроме upcast нет. Слот тратится после каста. Концентрация есть.
    9 classes/ClassFeatureHelper.kt:30-88 Production-путь активации фич: detect по подстроке имени → canAfford → spendCost; эффект здесь НЕ резолвится (резолв в EffectSpec-потребителях, прецедент Rage через rage_active buff).
    10 TurnResolver.kt:268-272 Каст парсится префиксом cast <spell_id> из текста хода — точка расширения для модификаторов метамагии.

    Proposed Options¶

    По B (Wild Shape — глубина среза):

    Вариант A: полная инфраструктура + малый каталог (3 зверя) — принято. - Плюсы: каноничная семантика (отдельный HP-пул, overflow-урон при реверте, статы/AC/атака зверя); каталог расширяем данными; gates (no spellcasting в форме) — канон. - Минусы: крупнейший из трёх блоков (новое состояние + каталог + маршрутизация урона). - Решение архитектора.

    Вариант B: Wild Shape как self-buff (бафф AC/атаки без HP-пула) — отклонено. - Минусы: теряется ключевая семантика (форма как «второй запас HP»); фальшивая механика, которую придётся переделывать.

    По C (Metamagic — как игрок объявляет модификацию):

    Вариант A: синтаксис-модификатор в тексте хода (cast <spell> quickened/heightened) — принято. - Плюсы: явное agency игрока (канон — выбор при касте); малая точка расширения парсера (факт #10); тестируемо. - Минусы: не естественный язык (пока Structured Intent G-007/G-008 не закрыт). - Решение архитектора.

    Вариант B: auto-режим (движок сам решает тратить очки) — отклонено. - Минусы: метамагия — осознанный выбор цены/эффекта; авто-режим сжигает очки непредсказуемо (см. отклонённый Вариант B в ADR-0031 D1).

    Вариант C: ждать Structured Intent — отклонено. - Минусы: блокирует 3.7c на G-007/G-008; Вариант A совместим с будущим intent.

    Decision¶

    A. Channel Divinity — Turn Undead (без undead-гейта)¶

    1. A1. StatusId.TURNED («Обращён», kind CLASS_EFFECT — Turned не condition из PHB Appendix A): добавляется в ATTACK_BLOCKERS (обращённый не может атаковать носителя канала; канон: действия — только Dash/побег, без реакций). Полная блокировка действий НЕ ставится (канон позволяет Dash).
    2. A2. Turn Undead — activatable-фича cleric L2: ACTION, cost 1 CHANNEL_DIVINITY; враг делает WIS-сейв против spell save DC клерика (SaveDcSpec.FromCaster, ADR-0017); провал → TURNED на 10 раундов (duration-лайфцикл ADR-0014). Данные — effect: у фичи «Божественный канал» (classes.yml), composite = spendresource + status TURNED (FromCaster).
    3. A3. Отклонение от канона (принято, фаза 4): без creature type гейт «только undead» невозможен (факт #2) — Turn Undead работает на любого врага. Регистрируется gap. «Destroy Undead» (L5+) — отложен туда же. Опции доменов (Preserve Life и пр.) — отложены в subclass-цикл (данные доменов narrative).

    B. Wild Shape — полная инфраструктура (Вариант A)¶

    1. B1. Состояние формы: CharacterState.wildShape: WildShapeState? — formId, formHp, maxFormHp (форма, текущий и максимальный HP зверя). Персистится в participantsJson (data class, без sealed — сериализация тривиальна, симметрия l1Choices).
    2. B2. Каталог зверей: beasts.yml + BeastRegistry (симметрия RaceRegistry/BackgroundRegistry). Поля: id, name, cr, hp, ac, attackBonus, damageDice, attributes(STR/DEX/CON), speed. Стартовый набор (канон CR ≤ 1/4, без fly/swim для L2): wolf, giant_rat, cat. Расширение — данные.
    3. B3. Активация: ACTION, cost 1 WILD_SHAPE; в форме — AC, физические атрибуты, бросок атаки и урон зверя (подмена в точках расчёта); входящий урон идёт в formHp; при formHp ≤ 0 — реверт, overflow-урон переносится на HP персонажа (канон). Реверт — bonus action (команда revert) либо автоматически на 0. В форме каст запрещён (канон; гейт в canCast). Длительность (часы) в боевом MVP не экспайрится — комментарий в коде.
    4. B4. Гейты данных: у фичи «Дикий облик» — effect: composite (spendresource + grantform?) — НЕТ: форма требует выбора зверя, поэтому обслуживается кодом (как ON_ATTACK_ROLL в ADR-0031 D1), НЕ общим FeatureEffectResolver. Синтаксис: wildshape <beast_id> / revert.

    C. Metamagic — choice + два модификатора (Вариант A)¶

    1. C1. Данные выбора: фича «Метамагия» получает choice: multiple, maxChoices: 2 с 8 каноническими опциями (careful/distant/empowered/ extended/quickened/heightened/subtle/twinned); существующий MetamagicChoice-маппинг активируется (факт #7); picks → l1Choices.
    2. C2. Реализуются два модификатора (дёшевы в текущем движке, покрывают обе оси «экономия/сейв»):
    3. Quickened Spell — 2 очка чар: каст как bonus action вместо action (ActionEconomy, ADR-0010). Синтаксис: cast <spell> quickened.
    4. Heightened Spell — 3 очка чар: цель с помехой на первый сейв против этого заклинания (AdvDisadvResolver, ADR-0013/0019). Синтаксис: cast <spell> heightened. Гейты: модификатор ∈ l1Choices, очков хватает (spend SORCERY_POINTS), иначе модификатор игнорируется с записью в лог/ответ.
    5. C3. Остальные 6 опций — данные в choice (описания по PHB), механика отложена: Empowered (reroll кубов урона) — нужен reroll-хук; Extended (длительность ×2) — нужен контекст длительности в точке каста; Distant/ Subtle — в движке нет дистанции/компонент-проверок (косметика); Careful/ Twinned — одновраговый MVP.

    Consequences¶

    Плюсы¶

    • Три класса (cleric/druid/sorcerer) получают играбельные сигнатурные механики.
    • Wild Shape — первый «внешний» каталог существ, прототип bestiary для ФАЗЫ 4.
    • Metamagic choice активирует спящий MetamagicChoice-путь (факт #7) без новой инфраструктуры.

    Минусы¶

    • Turn Undead без undead-гейта — временное отклонение от канона (gap, ФАЗА 4).
    • Синтаксис-модификаторы (wildshape wolf, cast x quickened) — не свободный язык; смягчается будущим Structured Intent.

    Риски¶

    • Маршрутизация урона в форме — новая ветвь в единой точке урона (DamageResolver/SessionService): риск пропустить путь урона (спеллы врага, хазарды). Митигация: тесты на каждый путь урона по форме.
    • TURNED в ATTACK_BLOCKERS сильнее канона в дуэли (враг теряет атаку полностью) — принято для одноврагового MVP, пересмотр при ФАЗЕ 4 (монстры с типами и AI отступления).

    Отложено¶

    • Creature type на Enemy/archetypes + undead-гейт Turn Undead + Destroy Undead (ФАЗА 4, gap).
    • Опции доменов Channel Divinity (subclass-цикл).
    • 6 опций Metamagic (empowered/extended/careful/distant/subtle/twinned) — механика, данные есть.
    • Расширение каталога зверей (CR 1/2 @L4, fly/swim @L8) — данные.
    • Длительность Wild Shape (часы = level/2) — вне боевого MVP.
