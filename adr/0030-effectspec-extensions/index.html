    ADR-0030: EffectSpec Extensions — Ki / Superiority / Channel Divinity / Wild Shape / Metamagic¶

    Status¶

    Accepted

    Context¶

    ADR-0029 ввёл EffectSpec (данные) + FeatureEffectResolver (поведение) как единый механизм «фича → StateChange». Попытка 3.7b2a (Ki/Monk) вскрыла, что текущий EffectSpec не покрывает 5 классов эффектов, необходимых для Ki/Superiority/Channel Divinity/Wild Shape/Metamagic. Расширяем ADR-0029 (не заменяем).

    5 пробелов, вскрытых 3.7b2a (Ki)¶

    1. Трата ресурса. ResourceEffect резолвится только в RestoreClassResource (FeatureEffectResolver.kt:96). Списания Ki-очков как эффекта нет — есть только SpendClassResource как отдельный StateChange (GameState.kt:1366).
    2. Статичный saveDC. DebuffEffect.saveDc: Int? (EffectSpec.kt:41) — константа. Ki save DC = 8 + PB + WIS (PHB гл.3, Monk) динамичен — невыразим.
    3. Безусловный статус. DebuffEffect всегда идёт через спасбросок (ApplyDebuff, GameState.kt:1328). ApplyStatus (GameState.kt:1234) существует, но не имеет EffectSpec-формы: DODGE/DISENGAGE-подобные статусы невыразимы как данные.
    4. Дополнительные атаки. GrantActionEffect игнорирует actionType и всегда выдаёт GrantExtraAction(1) (FeatureEffectResolver.kt:95). Экономия действий (GameState.kt:1430-1454) покрывает только основные действия. Flurry of Blows (2 безоружные бонус-атаки) невыразима.
    5. Движение. Dash/Disengage эмитят пустые stateChanges (TurnResolver.kt:686-700); DODGE — хардкод ApplyStatus (TurnResolver.kt:674-683). Нет EffectSpec для манёвров (Step of the Wind = Dash/Disengage).

    Чего НЕ найдено (grep → 0)¶

    • Типизированный AttackType enum (только строки "unarmed"/"melee"/"ranged" в dsl/ActionWhitelist.kt:130,215 и ActionParser.kt).
    • SpendResourceEffect / StatusEffect / SaveDcSpec / GrantExtraAttacks / MovementEffect / DashEffect / DisengageEffect — ноль.
    • Счётчик дополнительных атак в ActionEconomy — ноль (только extraActionsAvailable).

    Канон (PHB гл.3)¶

    • Ki save DC = 8 + proficiency bonus + Wisdom modifier (Monk, PHB p.78).
    • Flurry of Blows: после Attack-действия, 1 ki → 2 безоружные бонус-атаки.
    • Step of the Wind: 1 ki → Dash или Disengage как бонусное действие.
    • Patient Defense: 1 ki → Dodge как бонусное действие.
    • Stunning Strike: при попадании, 1 ki → цель делает CON-спасбросок против Ki save DC, провал → STUNNED.

    Proposed Options¶

    Рекомендация архитектора помечена жирным.

    A. Куда класть расширения. - A1: новый sealed-тип FeatureEffectExtension параллельно EffectSpec — второй механизм, рассинхрон. - A2: расширять EffectSpec (ADR-0029 B1) — единый sealed-интерфейс.

    B. Трата ресурса. - B1: SpendResourceEffect(resourceId, amount) — симметрия ResourceEffect; → SpendClassResource. - B2: поле direction: SPEND|RESTORE в ResourceEffect — enum-флаг, ломает читаемость.

    C. Статус без спаса. - C1: StatusEffect(condition, saveDc: SaveDcSpec?, duration, target) — отдельно от DebuffEffect. - C2: переиспользовать DebuffEffect с saveDc = null — смешение семантики «со спасом»/«без спаса».

    D. Динамический saveDC. - D1: SaveDcSpec sealed: FixedDc / FromCaster(ability) / FormulaDc — прецедент CastingStats (ADR-0017). - D2: поле ability: Ability? прямо в DebuffEffect — ad-hoc, не покрывает formula-скейл.

    E. Дополнительные атаки. - E1: GrantExtraAttacks(count, attackType) + enum AttackType — расширение ActionEconomy. - E2: переиспользовать GrantExtraAction с actionType — экономия действий не покрывает бонус-атаки.

    F. Движение. - F1: MovementEffect-семантика: DODGE → StatusEffect(DODGE); Dash/Disengage → отдельные EffectSpec. - F2: строковый маркер movement: "dash" — не типизировано.

    G. ADR-0011. - G1: это расширение ADR-0029, не параллельная форма — НЕ дубль. - G2: фиксировать как дубль #15 — преждевременно (нет второго source of truth).

    H. Объём. - H1: только ADR (design); реализация — 3.7b2a-restart. - H2: ADR + код — нарушает «один цикл = один фокусный шаг».

    Decision¶

    A. Место (A2)¶

    Расширяем sealed interface EffectSpec (ADR-0029 B1). Нового sealed-типа НЕ вводим: Ki/Superiority/Channel Divinity — те же «фича → StateChange», что и существующие 9.

    B. SpendResourceEffect (B1)¶

    Симметрично ResourceEffect (восстановление), но в обратную сторону:

    /** Трата классового ресурса (Ki/Superiority/Channel Divinity/Sorcery). */
data class SpendResourceEffect(
    val resourceId: String,      // KI, SUPERIORITY, CHANNEL_DIVINITY, SORCERY_POINTS
    val amount: Int = 1,
) : EffectSpec

    Резолв: StateChange.SpendClassResource(resourceId, amount) (уже есть, GameState.kt:1366).

    C. StatusEffect (C1)¶

    Отдельно от DebuffEffect. DebuffEffect = «условие со спасом»; StatusEffect = «наложить статус» (включая безусловные DODGE/STUNNED):

    /** Наложить статус на цель (включая безусловные: DODGE, RAGE, HIDDEN). */
data class StatusEffect(
    val condition: StatusId,
    val saveDc: SaveDcSpec? = null,       // null → безусловное наложение
    val duration: Int = 1,
    val target: String = StateTarget.PLAYER,
) : EffectSpec

    Резолв: StateChange.ApplyStatus(condition, target, duration, dc) (уже есть, GameState.kt:1234).

    D. SaveDcSpec (D1)¶

    Динамический DC — прецедент CastingStats (ADR-0017, 8 + PB + mod):

    /** Сложность спасброска эффекта фичи (Ki: 8 + PB + WIS). */
sealed interface SaveDcSpec
data class FixedDc(val value: Int) : SaveDcSpec                       // статичный (Stunning Strike при фикс.)
data class FromCaster(val ability: Ability) : SaveDcSpec              // 8 + PB + ability.mod (Ki: WIS)
data class FormulaDc(val formula: String) : SaveDcSpec                // замкнутая формула (Metamagic, 3.7c)

    FromCaster резолвится через 8 + ProficiencyBonus.of(level) + ability.modifierOf(attributes) (тот же приём, что CastingStats.of, CastingStats.kt:16-25). FormulaDc — замкнутая формула-маркер (не eval), как FormulaScaling (ScalingSpec.kt:35).

    E. GrantExtraAttacks (E1)¶

    Расширение ActionEconomy для Flurry of Blows:

    /** Дополнительные атаки (Flurry of Blows: 2 безоружные бонус-атаки). */
data class GrantExtraAttacks(
    val count: Int = 2,
    val attackType: AttackType = AttackType.UNARMED_MELEE,
) : EffectSpec

/** Тип атаки для доп. атак (новый enum — раньше только строки в DSL). */
enum class AttackType { UNARMED_MELEE, WEAPON_MELEE, RANGED }

    Реализация: ActionEconomy.extraAttacks: List<AttackType> (счётчик per-type) + StateChange.GrantExtraAttacks(count, attackType). Резолв добавляет count атак типа attackType в пул доп. атак; кап на ход — «2 в ход, не 4» (см. Risks).

    F. MovementEffect (F1)¶

    DODGE — это уже StatusId.DODGE (StatusId.kt:36), поэтому НЕ отдельный вариант, а StatusEffect(StatusId.DODGE). Dash/Disengage — отдельные EffectSpec:

    /** Рывок (Dash) — Step of the Wind. */
data object DashEffect : EffectSpec
/** Отход (Disengage) — Step of the Wind. */
data object DisengageEffect : EffectSpec

    Реализация: новые StateChange.Dash / StateChange.Disengage (сейчас эмитят пустые stateChanges, TurnResolver.kt:686-700).

    G. ADR-0011 (G1)¶

    ADR-0011 (single source of truth) — НЕ дубль: ADR-0030 — расширение ADR-0029, а не параллельная форма. Записи в реестр дублей ADR-0011 НЕ требуется.

    H. Объём (H1)¶

    Только ADR (design, без кода). Реализация — 3.7b2a-restart.

    Consequences¶

    Плюсы¶

    • Покрывает Ki/Superiority/Channel Divinity/Wild Shape/Metamagic — 5 циклов 3.7b/c одним расширением.
    • Динамический SaveDcSpec.FromCaster закрывает Ki save DC (8+PB+WIS) без хардкода.
    • GrantExtraAttacks — прецедент для Rogue Cunning Action (бонус-действие без ресурса).
    • StatusEffect унифицирует «наложить статус» (DODGE/HIDDEN/STUNNED/RAGE) — убирает inline-хардкод TurnResolver.

    Минусы¶

    • EffectSpec растёт: 8 → 13 вариантов (по базе ADR-0029 B1; фактически 9 → 14 с учётом ResistanceEffect).
    • ActionEconomy расширяется (поле доп. атак) — усложнение экономии действий.
    • ADR-0029 теперь читается вместе с ADR-0030 (два документа вместо одного).

    Риски¶

    • GrantExtraAttacks ломает экономию действий. Риск: два GrantExtraAttacks в ход → 4 атаки вместо 2. Митигация: кап на ход («2 в ход, не 4») + тест на кап.
    • StatusEffect vs DebuffEffect — структурное совпадение. Митигация: решено НЕ объединять (см. стоп-условие 1); DebuffEffect — потенциальный near-duplicate, при необходимости перевыражается как StatusEffect(FixedDc(...)) в 3.7+.
    • MovementEffect заденет TurnResolver. Риск: сейчас Dash/Disengage эмитят пустые stateChanges (TurnResolver.kt:686-700); добавление StateChange затронет боевой цикл. Митигация: инкрементальная замена хардкода без изменения поведения вне боя.
    • SaveDcSpec.FromCaster зависит от Ability + ProficiencyBonus — переиспользуем CastingStats (ADR-0017), не дублируем формулу.

    Отложено¶

    • Реализация Ki — 3.7b2a-restart (после принятия ADR-0030).
    • Superiority — 3.7b2b.
    • Channel Divinity / Wild Shape / Metamagic — 3.7c.
    • Перевыражение DebuffEffect через StatusEffect(FixedDc) — отдельный рефакторинг (после 3.7c).

    Untouched in this ADR¶

    • ADR-0029 не меняем (Accepted = источник истины; расширения — новый ADR).
    • Код (EffectSpec.kt, FeatureEffectResolver.kt, GameState.kt, TurnResolver.kt, CastingStats.kt, ActionType.kt) — цикл 3.7b2a-restart.
    • Frontend — ФАЗА 6.
    • SpellEffect / Spell.kt / унификация со SpellEffect (ADR-0029 I1) — отдельный цикл.
