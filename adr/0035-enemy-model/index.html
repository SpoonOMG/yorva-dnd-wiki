    ADR-0035: Enemy Model — creature type, damage type, CR (ФАЗА 4 core)¶

    Status¶

    Accepted

    Context¶

    ФАЗА 4 (Monsters). Разведка (2026-10-02) подтвердила четыре дефекта модели врага и разблокируемые ими механики.

    Факты (файл:строка):

    # Файл:строка Факт
    1 rules/GameState.kt:773-822 Enemy: name/hp/ac/attackBonus/damageDie/damageBonus/statusSaveBonus/resistances… Нет damageType (G-001), creatureType (G-046), cr, атрибутов/навыков.
    2 changes/0036-creature-archetypes.yaml Архетипы: 46 строк rank×level + swarm (0044). Колонок damage_type/creature_type/cr нет; после 0036 — только UPDATE/INSERT.
    3 TurnResolver.kt:3241-3282 Атака врага: StateChange.Damage(…, PLAYER) без типа (G-001) — расовые сопротивления игрока (ADR-0012, цикл #7) не работают против врагов. Также 2d8 → бросается одна кость (regex d(\d+)).
    4 CatalogService.kt:298-334 ArchetypeRow/mapArchetype читают все колонки 0036; rank в Enemy не прокидывается.
    5 TurnResolver.kt:1479-1505 instantiateArchetypeEnemy — единая точка создания врага из архетипа (SPAWN_ENEMY, SessionService.kt:3753).
    6 TurnResolver.kt:556-619 Turn Undead: сейв → TURNED, гейт по типу существа невозможен (комментарий classes.yml:450-451). Destroy Undead (L5) не реализован.
    7 TurnResolver.kt:1147, 2209 resolveAttackCatalog и generic spell мутируют enemy.hp без DamageResolver — сопротивления/иммунитеты врага обходятся (G-014 поверхность). Полная консолидация отложена ADR-0011 #4 (вариант C).
    8 classes/ — нет Contested checks (атлетика vs атлетика/акробатика): у Enemy нет атрибутов/навыков — данных нет.
    9 SpellService.kt:106-180 Material components (SpellComponents.materialConsumed/Cost, ADR-0028 D4) не читаются при касте. StateChange.ConsumeItem существует (GameState.kt:1307, поиск по имени).

    Канон 5e: 14 типов существ; Destroy Undead — провал сейва → нежить с CR ≤ порога (L5: 1/2, L8: 1, L11: 2, L14: 3, L17: 4) уничтожается вместо обращения; сопротивления применяются к любому типизированному урону.

    Proposed Options¶

    По creature type (форма данных):

    Вариант A: enum CreatureType (14 канонических) + колонка в archetypes + поле в Enemy — принято. - Плюсы: закрытый словарь (как StatusId/DamageType); гейт данных через EffectCondition; миграция одна. - Минусы: homebrew-типы требуют кода — принято (14 типов покрывают SRD). - Решение архитектора.

    Вариант B: свободная строка — отклонено. Расходится с конвенцией кодовой базы (StatusId/DamageType — enum), строковые опечатки молча ломают гейты.

    По CR для Destroy Undead:

    Вариант A: derive CR из xp по канонической таблице XP↔CR — принято. - Плюсы: без схемы/данных (xp уже есть, 0036); таблица конечна и канонична. - Минусы: CR неявен в данных — принято (архетипы generic rank×level, xp задан). - Решение архитектора.

    Вариант B: колонка cr — отклонено. Второй источник истины к xp (ADR-0011); рассинхрон гарантирован.

    Decision¶

    1. D1. CreatureType enum (14 канонических: ABERRATION…UNDEAD) в rules/. Миграция Liquibase 0046-creature-archetype-type.yaml: creature_archetypes += creature_type VARCHAR(32) DEFAULT 'humanoid'
    2. damage_type VARCHAR(32) NULL (NULL = бестиповый, канон-дефолт). ArchetypeRow/mapArchetype/instantiateArchetypeEnemy прокидывают оба.
    3. D2. Enemy += creatureType: CreatureType = HUMANOID, damageType: DamageType? = null. applyEnemyTurn эмитит Damage с типом (G-001) → сопротивления игрока работают. Попутный фикс: 2d8 → обе кости (parse полного NdM, не одной) — тот же блок, отдельный тест.
    4. D3. Undead-гейт данными (G-046): EffectCondition += TargetCreatureType(types); Turn Undead effect += condition undead; resolveEnemyStatusActivation оценивает условие с enemy. Не-undead → фича недоступна (no_roll с причиной), ресурс не тратится.
    5. D4. Destroy Undead: в той же точке: провал сейва + enemy UNDEAD + crOf(enemy.xpReward) ≤ threshold(clericLevel) (канон-таблица) → враг уничтожается (defeated, XP начисляется) вместо TURNED. Порог по уровню клерика: 5→0.5, 8→1, 11→2, 14→3, 17→4.
    6. D5. G-014 (точечно, не консолидация): resolveAttackCatalog и generic spell пропускают урон через DamageResolver.apply перед мутацией hp (сопротивления/иммунитеты врага перестают обходиться). Полная консолидация Damage(ENEMY)-пути остаётся Deferred (ADR-0011 #4, вариант C).
    7. D6. Contested checks — Deferred. У Enemy нет атрибутов/навыков; прокси изобретать не будем. Зависимость: реальные statblock'и монстров (ФАЗА 4 продолжение, монстр-каталог).
    8. D7. Material components (ADR-0028 D4): resolveCastSpell: если components.materialConsumed == true — требуется предмет в инвентаре (матчинг по имени material, case-insensitive) → ConsumeItem при касте; нет предмета → отказ каста с причиной. Компоненты с materialCost != null (золото) — не гейтятся (экономики нет — Deferred).

    Consequences¶

    Плюсы¶

    • G-001/G-046 закрыты; Turn Undead каноничен (undead-гейт + Destroy Undead).
    • Сопротивления работают симметрично игрок↔враг (D2 + D5).
    • Фундамент монстр-каталога: тип/CR — первые поля statblock'а.

    Минусы¶

    • Generic-архетипы получают дефолтный тип humanoid — семантически грубо (митигация: реальные монстры — отдельный каталог с типами, ФАЗА 4 продолжение).
    • CR из xp — неявность (митигация: канон-таблица, тест на границы).

    Риски¶

    • damageType у существующих спавнов NULL → урон врага остаётся бестиповым (поведение не меняется до данных). Миграция — только дефолт type.
    • D5 меняет итоговый урон по resistant-врагам — тесты с конкретными числами могут дрейфануть; чинить в том же коммите.

    Отложено¶

    • Contested checks (D6). Монстр-каталог с полными statblock'ами (атрибуты, навыки, CR явный). Золото/materialCost-гейт (D7). Консолидация Damage(ENEMY) (ADR-0011 #4). Учёт creature type в остальных механиках (спеллы типа protection from evil — при появлении).
