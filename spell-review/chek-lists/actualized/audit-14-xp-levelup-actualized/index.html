    Детали¶

    14.1 Модель XP/уровня¶

    • Утверждение: level/xp, xpTriggers, currentScene, pendingASI, classLevels, ClassLevelEntry.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: level/xp GameState.kt:342-343, xpTriggers:431, currentScene:441, pendingASI:444, require(pendingASI>=0):524, classLevels:483, ClassLevelEntry:673-676 (все строки сдвинуты).
    • Целевое поведение (5e): модель уровня/XP и мультикласс-задел.
    • Расхождение: только дрейф строк; totalLevel не вычисляется.
    • Что делать: не требуется.

    14.2 Таблица уровней¶

    • Утверждение: кумулятивная level-table.yml + LevelTableRegistry.
    • Статус: ✅ VALID
    • Текущая реализация: level-table.yml:1-61 (L2=300 … L20=355000); forLevel:52, xpFor:53, canLevelUp:61-64.
    • Целевое поведение (5e): пороги XP и proficiency bonus по таблице 5e.
    • Расхождение: нет.
    • Что делать: не требуется.

    14.3 Источники XP (движок)¶

    • Утверждение: бой/добивание/реакция/небоевые/исследование/NPC.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: nonCombatXp TurnResolver.kt:1062-1063, addExplorationXp:1077-1090; xpForEnemy :1327; ReactionResolver.kt:87 (VALID), :184-190; эмиссии TurnResolver.kt:858,963,971,975,1087,1112,1290,1319 и др. (номера сдвинуты).
    • Целевое поведение (5e): XP за победу, социальные/исследовательские задачи.
    • Расхождение: только дрейф строк.
    • Что делать: не требуется.

    14.4 Milestone XP за сцену¶

    • Утверждение: milestone за SetScene, один раз на сцену; computeSceneTransition.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: SessionService.kt:2368-2380 (было :2068-2082); computeSceneTransition:2313-2322 (было :2014-2023); MILESTONE_BASE=50 XpRules.kt:17.
    • Целевое поведение (5e): награда за вехи/смену сцены.
    • Расхождение: только дрейф строк.
    • Что делать: не требуется.

    14.5 Авто-каскад GainXp¶

    • Утверждение: самостоятельный мини level-up (HP, hit dice, слоты, pendingASI).
    • Статус: ⚠️ CHANGED
    • Текущая реализация: SessionService.kt:2490-2521 (было :2188-2219); xpForNextLevel:2850-2871 (было :2546-2567), значения те же.
    • Целевое поведение (5e): единый level-up со всеми шагами класса.
    • Расхождение: авто-путь не обрабатывает features/subclass/ASI-выбор/classResources/classLevels.
    • Что делать: вопрос для ADR (унификация путей).

    14.6 Ручной LevelUpService.levelUp¶

    • Утверждение: детерминированный level-up; обёртка в SessionService.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: LevelUpService.kt:94-277 (VALID, строки не сдвинулись); обёртка SessionService.levelUp:2136-2152 (было :1836-1853); endpoint SessionController.kt:192-200.
    • Целевое поведение (5e): пошаговый level-up с выбором ASI/feat/подкласса/заклинаний.
    • Расхождение: только дрейф строк обёртки.
    • Что делать: не требуется.

    14.7 HP при level-up¶

    • Утверждение: две разные формулы (авто vs ручной), превью без ретро-CON/tough.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: авто (hitDie/2)+1+conMod, hp=maxHp SessionService.kt:2497-2502; ручной LevelUpService.kt:175-201 (VALID), avgHitDie:306-308, превью :360-363.
    • Целевое поведение (5e): фиксированный прирост HP (avg hit die или бросок) + CON.
    • Расхождение: формулы расходятся; превью не учитывает ретро-CON и tough.
    • Что делать: вопрос для ADR (единая формула HP).

    14.8 ASI (pendingASI/allocateASI)¶

    • Утверждение: авто-инкремент hardcode; ручной обнуляет pendingASI.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: авто SessionService.kt:2513-2515 (hardcode {4,8,12,16,19}); allocateASI:1986-2054 (было :1686-1755); ручной обнуляет LevelUpService.kt:270.
    • Целевое поведение (5e): ASI на уровнях класса (у warrior/rogue — доп. уровни).
    • Расхождение: авто-путь игнорирует cls.asiLevels; ручной теряет накопленные ASI.
    • Что делать: вопрос для ADR.

    14.9 ASI vs Feat¶

    • Утверждение: XOR, prereq не валидируется; эффект только tough.
    • Статус: ✅ VALID
    • Текущая реализация: LevelUpService.kt:108 (XOR), :112-116; prereq — только комментарий :114; tough :188-196, повторная ветка пуста :194-196.
    • Целевое поведение (5e): при ASI — либо +2/+1+1, либо feat с проверкой требований.
    • Расхождение: требования черт не проверяются; реализован только tough.
    • Что делать: открытый вопрос.

    14.10 Подкласс на L3¶

    • Утверждение: выбор подкласса только в ручном пути.
    • Статус: ✅ VALID
    • Текущая реализация: LevelUpService.kt:124-135 (требование подкласса), :126 — nextLevel==3 && subclassId==null; авто-путь не выбирает.
    • Целевое поведение (5e): подкласс на уровне, заданном классом.
    • Расхождение: авто-путь не присваивает subclassId.
    • Что делать: вопрос для ADR (унификация).

    14.11 Feature/spell choices¶

    • Утверждение: featureChoices есть в Kotlin/фронте, но нет в OpenAPI LevelUpRequest.
    • Статус: ✅ VALID
    • Текущая реализация: LevelUpRequest.featureChoices LevelUpService.kt:38; openapi.yaml LevelUpRequest:2129-2152 — поле featureChoices отсутствует (grep пуст); фронт LevelUpModal.tsx.
    • Целевое поведение (5e): выбор опций фич/заклинаний на level-up.
    • Расхождение: контракт не синхронизирован.
    • Что делать: вопрос для API-контракта.

    14.12 Hit dice / spell slots / class resources¶

    • Утверждение: ручной полноценный; авто упрощён.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: ручной LevelUpService.kt:249-256,310-358 (VALID); авто SessionService.kt:2503-2512 (было :2202-2210) — FULL-таблица слотов, без HALF/PACT.
    • Целевое поведение (5e): слоты по типу заклинателя (FULL/HALF/PACT), hit dice по уровню.
    • Расхождение: авто-путь использует FULL-таблицу для любого заклинателя.
    • Что делать: вопрос для ADR.

    14.13 xpTriggers/SetScene/ClearXpTriggers/AddXpTrigger¶

    • Утверждение: ClearXpTriggers не эмитится; очистки по смене сцены нет.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: StateChange.ClearXpTriggers GameState.kt:1175 (было :1136); обработка SessionService.kt:2719-2727 (было :2415-2423); эмиссия по-прежнему не найдена.
    • Целевое поведение (5e): сброс разовых триггеров по смене сцены.
    • Расхождение: комментарий XpRules.kt:9 не соответствует коду.
    • Что делать: открытый вопрос.

    14.16 Смысл xp расходится между путями¶

    • Утверждение: авто хранит остаток, ручной/фронт/превью — кумулятив.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: авто xp -= xpForNextLevel(level) SessionService.kt:2492-2493; кумулятив LevelTableRegistry.kt:61-64, levelUp.ts:12; пример L2→L3: авто 600 (:2852) vs таблица 900 (level-table.yml:8-9).
    • Целевое поведение (5e): единый смысл XP.

    • Что делать: вопрос для ADR (каноничный смысл XP).
