    [18.2] Разрешение опасности¶

    • Утверждение (старое): resolveHazard (TurnResolver.kt:1358-1424); damageType не влияет на урон; срабатывание одиночное.
    • Статус: ⚠️
    • Текущая реализация: TurnResolver.kt:1422-1489; спасбросок :1427-1451, DC (saveDc + dcOffset).coerceIn(5,30):1446-1447, урон Damage(damage, PLAYER, damageType):1461, статус :1464-1467; dispatch :579-587.
    • Целевое поведение (5e): hazard наносит урон/эффект по типу, применимому к resistances.
    • Расхождение: сохраняется — damageType эмитится, но не учитывается при вычитании HP; урон одиночный.
    • Что делать: обновить ссылку :1358-1424→:1422-1489.

    [18.3] Классификация опасностей¶

    • Целевое поведение (5e): корректная классификация типа опасности.
    • Расхождение: сохраняется; устарели ссылки :397-398→:450-451, :508-525→:568, :556→:616, :595→:655.

    [18.4] Ловушки¶

    • Статус: ✅

    • Целевое поведение (5e): жизненный цикл ловушки (обнаружение → обезвреживание/срабатывание).
    • Расхождение: нет — пробел сохраняется.
    • Что делать: оставить.

    [18.5] Difficult terrain / перемещение¶

    • Утверждение (старое): нет поля скорости/террейна; MOVE_DIFFICULT_TERRAIN в whitelist, но не в action_economy.yml.
    • Статус: ✅

    • Целевое поведение (5e): difficult terrain удваивает стоимость перемещения.
    • Расхождение: нет — пробел сохраняется.
    • Что делать: оставить.

    [18.6] Укрытие (cover/concealment)¶

    • Утверждение (старое): только условия whitelist hasCover/hasConcealment; в контекст не передаются.
    • Статус: ✅
    • Текущая реализация: action-whitelist-core.yaml:155; переменные в контекст не передаются (см. SessionService.kt:953-961, ActionParser.kt:83-88); расчёта укрытия в атаках нет.
    • Целевое поведение (5e): half/three-quarters/total cover даёт бонус к AC/DEX save.
    • Расхождение: нет — пробел сохраняется.
    • Что делать: оставить.

    [18.7] Освещение / тьма / тёмное зрение¶

    • Утверждение (старое): уровня освещения и darkvision нет; darkness_magic не разрешается (save_attribute=NULL).
    • Статус: ✅
    • Текущая реализация: darkness_magic с save_attribute=NULL; gate hazard.saveAttribute != null (TurnResolver.kt:582) уводит в resolveNoRoll; поля освещения/darkvision отсутствуют.
    • Целевое поведение (5e): lightly/heavily obscured, darkvision, помехи Perception в темноте.
    • Расхождение: нет — пробел сохраняется.
    • Что делать: оставить.

    [18.8] Падение / утопление / истощение¶

    • Утверждение (старое): падение — только через поломку объекта на врага (TurnResolver.kt:1485-1491); по игроку нет; истощение не инкрементируется.
    • Статус: ⚠️
    • Текущая реализация: fallDamagePercent только для врага (TurnResolver.kt:1484-1492); resolveGenericObject — урон врагу; exhaustion только уменьшается (RestService.kt:90,97, SessionService long rest); инкремента нет; HAZARD_DROWN→quicksand без урона.
    • Целевое поведение (5e): fall damage (1d6/10 ft), drowning/suffocation, exhaustion от среды/марша.
    • Расхождение: сохраняется; устарели ссылки :1485-1491→:1484-1492.
    • Что делать: обновить формулировку.

    • Расхождение: нет — пробел сохраняется (обновилась только ссылка :2086-2089→:2385).
    • Что делать: оставить; обновить ссылку.

    • Расхождение: сохраняется; устарели ссылки :1395-1397→:1458-1461, :1401→:1465, GameState.kt:1120→:1159.
