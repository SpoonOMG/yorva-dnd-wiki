    Детали¶

    13.1 Каталог и источник¶

    • Утверждение: два источника — item_archetypes (0022) и loot_items (витрина).
    • Статус: ⚠️ CHANGED
    • Текущая реализация: ItemArchetype ItemCatalogService.kt:21, findById:48, findByCategory:59, findByCategoryAndRarity:77, findAll:100, matchArchetype:115, mapRow:241-279 (было :243-281); LootShowcaseService.generateShowcase:123, toInventoryItem:199, ICON_CATEGORY_TO_ITEM:55-70, LOOT_CATEGORY_DEFAULT:73-77, resolveItemCategory:214-221 — строки совпали.
    • Целевое поведение (5e): единый справочник предметов с категорией, редкостью, бонусами.
    • Расхождение: только дрейф строк mapRow; attack_bonus по-прежнему не читается.
    • Что делать: не требуется (фактура верна).

    13.2 Магические бонусы¶

    • Утверждение: ItemBonuses (11 полей), attackBonus без источника, manaBonus не применяется.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: ItemBonuses GameState.kt:200-215 (без изменений); LootPowerTable.bonusesFor:48-56 (VALID); LootTable.generateBonuses:287-306 (было :237-256), POTION hpBonus=base 4:302-303.
    • Целевое поведение (5e): бонусы предмета (в т.ч. attack/charges) имеют источник и потребителя.
    • Расхождение: attackBonus не заполняется ни одной веткой; manaBonus не читается.
    • Что делать: открытый вопрос (источник attack_bonus).

    13.3 Attunement¶

    • Утверждение: поля/колонки/логики нет.
    • Статус: ✅ VALID
    • Текущая реализация: вхождения attunement/attune/attuned — 0; нет поля в InventoryItem (GameState.kt:231-258), нет колонки в 0022/loot_items.
    • Целевое поведение (5e): requires attunement / лимит 3 настройки.
    • Расхождение: механика отсутствует полностью.
    • Что делать: вопрос для ADR (входит ли в скоуп).

    13.4 Charges¶

    • Утверждение: зарядов нет, только DSL-whitelist ссылается на несуществующую модель.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: action-whitelist-magic.yaml:97,100,103 (VALID); StateChange.ConsumeItem GameState.kt:1179 (было :1140), обработка SessionService.kt:2531-2537 (было :2229-2236); UseAction GameState.kt:218-224.
    • Целевое поведение (5e): charges + recharge у wand/staff/rod.
    • Расхождение: модели зарядов нет; расход — удаление по quantity.
    • Что делать: вопрос для ADR (magic item system).

    13.5 Potions¶

    • Утверждение: лечение из hpBonus, иначе 2d4; прочие бонусы зелья не применяются.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: resolveUseItem TurnResolver.kt:2144, зелье :2161-2188 (hpBonus :2170-2172, 2d4 :2179, GainXp :2178); POTION без слота GameState.kt:177; ContextBuilder :295-296,320-331 (было :247).
    • Целевое поведение (5e): зелье применяет свой эффект (heal/бафф) по правилам.
    • Расхождение: применяется только hpBonus; str_bonus «Эликсира богатыря» игнорируется.
    • Что делать: открытый вопрос (обобщить эффекты зелий).

    13.6 Scrolls¶

    • Утверждение: фиксированный урон из damageBonus без заклинания/DC/типа урона; изучения нет.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: свиток TurnResolver.kt:2188-2194 (было :2116-2129); scroll-fireball 0022:403-411 (VALID); SCROLL без слота GameState.kt:178.
    • Целевое поведение (5e): свиток кастует конкретное заклинание (спасбросок/DC/тип урона, расход по правилам).
    • Расхождение: плоский Damage в ENEMY; tags=aoe,fire не читаются.
    • Что делать: вопрос для ADR (семантика свитков).

    13.7 Wands/Staves/Rods¶

    • Утверждение: категорий WAND/STAFF/ROD нет; посохи → MELEE_WEAPON.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: ItemCategory GameState.kt:169-181 (без WAND/STAFF/ROD, VALID); inferCategoryFromName ItemCategoryInference.kt:10 (было :15), токен-матч :13-20; giftNounRegex SessionService.kt:3444 (было :3072).
    • Целевое поведение (5e): wand/staff/rod — отдельные магические предметы с charges.
    • Расхождение: классифицируются как оружие ближнего боя.
    • Что делать: вопрос для ADR (магические категории).

    13.8 Применение ItemBonuses¶

    • Утверждение: бонусы применяются только для надетых предметов со слотом; hpBonus/manaBonus на экипировке не работают.
    • Статус: ⚠️ CHANGED
    • Текущая реализация: equippedItems GameState.kt:585, equippedWeapon:589, effectiveAc:601, weaponDamageBonus:615, effectiveAttributes:623-642 (было :544-603); описание экипировки TurnResolver.kt:2295-2300 (было :2206-2211); ReactionResolver.kt:174 (VALID).
    • Целевое поведение (5e): надетый предмет даёт все свои бонусы.
    • Расхождение: MISC без слота не даёт AC/атрибутов; hpBonus/manaBonus на экипировке не работают; EXPLOSIVE без ветки резолва.
    • Что делать: открытый вопрос (применение hp/mana бонусов, резолв EXPLOSIVE).
