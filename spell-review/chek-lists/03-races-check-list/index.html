    Принятые решения по дырам¶

    2.3.1 · Нет каталога рас — Создать races.yml¶

    • По паттерну classes.yml: данные в resources/, загрузчик-реестр.

    2.3.2 · Нет модели Race — Создать Race + RacialTrait¶

    • Race(id, name, description, abilityBonuses, speed, size, languages, traits, subraces).

    2.3.3 · Нет RacialTrait — Переиспользовать поля ClassFeature¶

    • Поля actionType/resourceId/usesPerLevel/recharge/choice (CharacterClass.kt:51-65), чтобы traits были активируемыми. Иначе — снова «только текст».

    2.3.4 · Нет подрас — Nested list в races.yml¶

    • High Elf, Wood Elf, Hill Dwarf, Mountain Dwarf. + subraceId в состоянии.

    2.3.5 · Нет ability score increases — Применять ПОСЛЕ point-buy¶

    • Ядро решения — 2.3.13.

    2.3.6 · origin — только текст — Добавить raceId/subraceId¶

    • origin оставить как display-текст (портрет/промпт).

    2.3.7 · Нет влияния на speed — Добавить speed¶

    • См. 2.3.14.

    2.3.8 · Нет size — Добавить enum Size¶

    • TINY/SMALL/MEDIUM/LARGE.

    2.3.9 · Нет REST API — GET /api/races, GET /api/races/{id}¶

    • По паттерну ClassController.

    2.3.10 · 0 из 9 SRD-рас — Фазово¶

    • 9 SRD-рас + подрасы.

    2.3.11 · Расовые требования к классам — Отложить¶

    2.3.12 · Нет Custom Lineage — Этап 2; Homebrew Builder — этап 3¶

    • Бюджет очков traits — этап 3.

    2.3.13 · Point-buy vs расовые бонусы — Ядро: разделить базовые и расовые¶

    • Валидация point-buy — по базовым (8..15, бюджет 27, SessionService.kt:49-52,334-336). [ОБНОВЛЕНО: 2026-09-15: ссылки устарели → константы backend/app/src/main/kotlin/com/yorva/sessions/SessionService.kt:57-60, валидация — SessionService.kt:411-413.]

    • Хранить baseAttributes (для аудита) + итоговые attributes.

    2.3.14 · Speed не хранится — Добавить speed + резолв movement-флагов¶

    • Хранить speed в CharacterState.
    • Флаги hasClimbSpeed/hasSwimSpeed/hasFlySpeed сейчас мертвы: либо вычислять из traits, либо убрать из whitelist.

    • Grapple/Shove/оружие сейчас size не учитывают.

    Дополнения ревью (8 упущений)¶

    Уточнение к 2.3.3 · RacialTraitEffect (sealed class)¶

    ClassFeature не покрывает все типы расовых traits. Ввести RacialTraitEffect (sealed) с подтипами: PassiveModifier (+HP/level и т.п.), Resistance(damageType), Advantage(saveType), Immunity(condition), NaturalArmor(int), NaturalWeapon(weapon), SpellLike(spellId, level, recharge), SkillProficiency, WeaponProficiency, Language, Choice. Общие поля с ClassFeature — только actionType, resourceId, recharge, choice.

    2.3.26 · Формат features в CharacterState — Новая¶

    • Разделить поля вместо одного features:
    • classFeatures: List<ClassFeature> — классовые.
    • subclassFeatures: List<ClassFeature> — подкласс.
    • racialTraits: List<RacialTrait> — расовые.
    • featEffects: List<FeatEffect> — черты.
    • Факт: CharacterState.features отсутствует; решение 2.1.12 (одно поле) уточняется в пользу разделения.

    2.3.27 · Порядок обработки creationMethod — Новая¶

    1. Валидация point-buy (базовые attributes 8..15, бюджет 27).
2. Выбор расы (raceId / custom_lineage / homebrew).
3. Применение расовых бонусов.
4. Применение расовых traits.
5. Заполнение CharacterState.
    - STANDARD: point-buy → расовые бонусы (races.yml). - CUSTOM_LINEAGE: point-buy → свободные бонусы (+2/+1 или +1/+1/+1), 1 feat, 1 skill, darkvision/1 skill. - HOMEBREW: point-buy → валидация бюджета traits (отдельно от point-buy) → бонусы. - Point-buy применяется во всех трёх методах; отличается только источник расовых бонусов и бюджет traits.
