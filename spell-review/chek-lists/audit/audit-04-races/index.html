    Фактура из кода¶

    2.3.1 Каталог рас¶

    • Где: backend/app/src/main/resources/ (файла races.yml нет); эталон — backend/app/src/main/resources/classes.yml, backend/app/src/main/kotlin/com/yorva/classes/ClassRegistry.kt:18.
    • Что: каталога рас нет ни в ресурсах, ни в виде реестра. Полный список YAML ресурсов рас не содержит.
    • Пример: 
      action_economy.yml  application.yml  backgrounds.yml  classes.yml  dsl-registry.yml
dsl-templates.yml  feats.yml  level-table.yml  loot-whitelist.yml  reaction_triggers.yml
semantic-dictionary.yml  settingReskin.yml  skills.yml  subclasses.yml  tools.yml

    2.3.2 Модель Race/RacialTrait¶

    • Где: поиск по backend/app/src/main/kotlin/ — 0 вхождений Race, RacialTrait, RaceRegistry, RaceController.
    • Что: доменных моделей расы нет. Ближайший аналог — data class ClassFeature (backend/app/src/main/kotlin/com/yorva/classes/CharacterClass.kt:51).
    • Пример: 
      data class ClassFeature(
    val name: String,
    val level: Int,
    val description: String,
    val actionType: com.yorva.rules.FeatureActionType? = null,
    val resourceId: String? = null,
    val usesPerLevel: Map<Int, Int>? = null,
    val recharge: com.yorva.rules.RestType? = null,
    val choice: FeatureChoice? = null,
)

    2.3.3 Racial traits¶

    • Где: backend/app/src/main/resources/subclasses.yml:203 (единственное упоминание Darkvision); CharacterClass.kt:51-65.
    • Что: модели RacialTrait/RacialTraitEffect нет; Darkvision встречается только в описании классовой фичи подкласса и механически не обрабатывается.
    • Пример: 
      - { name: "Искусства тени", level: 3, description: "Minor Illusion, Darkness, Darkvision, Pass without Trace, Silence за 2 ки" }

    2.3.4 Subraces¶

    • Где: backend/app/src/main/kotlin/com/yorva/classes/SubclassRegistry.kt:38-50 (паттерн подклассов).
    • Что: подрас нет; subraceId в коде отсутствует. Есть только классовый Subclass с парсингом из subclasses.yml.
    • Пример: 
      val feats = featsRaw.map {
    ClassFeature(
        name = it["name"] as String,
        level = (it["level"] as? Int) ?: 3,
        description = it["description"] as? String ?: "",
    )
}

    • Пример: 
      newAttributes = applyAsi(state.attributes, req.asiChoice!!)
private fun applyAsi(attrs: Attributes, choice: Map<String, Int>): Attributes {

    2.3.6 origin vs raceId¶

    • Где: backend/app/src/main/kotlin/com/yorva/sessions/SessionDtos.kt:21; backend/app/src/main/kotlin/com/yorva/rules/GameState.kt:701; backend/app/src/main/kotlin/com/yorva/sessions/SessionService.kt:501; backend/app/src/main/kotlin/com/yorva/llm/ContextBuilder.kt:91-97; frontend/components/game/CharacterCreationWizard.tsx:246.

    • Пример:

val ac = 10 + attrs.dexMod

    2.3.16 Languages¶

    • Где: backend/app/src/main/kotlin/com/yorva/rules/GameState.kt:429; backend/app/src/main/kotlin/com/yorva/sessions/SessionService.kt:77-91,439-443; backend/app/src/main/resources/backgrounds.yml:7 и далее.

    2.3.25 Применение resistance в TurnResolver¶

    • Где: backend/app/src/main/kotlin/com/yorva/rules/TurnResolver.kt:2697.

    Открытые вопросы¶

    • В чек-листе (2.3.1) ActionWhitelist.conditionFor указан без пакета; в коде класс лежит в com.yorva.dsl (backend/app/src/main/kotlin/com/yorva/dsl/ActionWhitelist.kt:85) — путь в чеке требовал уточнения.
    • Условия движения в action-whitelist-core.yaml (hasClimbSpeed/hasSwimSpeed/hasFlySpeed) присутствуют, но conditionFor не вызывается вне определения — назначение флагов остаётся неопределённым (расчёта speed нет).
    • Файл backgrounds.yml содержит поле languages, однако код использует захардкоженный when (SessionService.kt:439-443); какой источник считать целевым — требует уточнения (относится к 2.3.16).
    • Раса нигде не участвует в бою: TurnResolver не содержит ни одной расовой ветки — подтверждение статуса 2.3.8.
