    Фактура из кода¶

    12.1 Модель death saves¶

    Где: rules/GameState.kt:343-346,480-489. 

    val isDead: Boolean = false,            // :343
val deathSaveSuccess: Int = 0,          // :345
val deathSaveFail: Int = 0,             // :346
...
require(deathSaveSuccess in 0..3)       // :480
require(deathSaveFail in 0..3)          // :481
@JsonIgnore val isUnconscious: Boolean get() = hp == 0 && !isDead && deathSaveFail < 3 && "Стабилен" !in statuses  // :489
    "Стабилен" входит в NO_ATTACK_STATUSES (GameState.kt:623) и исключает isUnconscious.

    12.2 Авто-спасбросок (падение в 0 HP)¶

    Где: rules/DeathRules.kt:12-14; sessions/SessionService.kt:970-985. 

    fun shouldAutoDeathSave(before: CharacterState, after: CharacterState): Boolean =
    !before.isUnconscious && !before.isDead &&
        before.hp > 0 && after.hp == 0 && !after.isDead

    val autoDeathSave = if (DeathRules.shouldAutoDeathSave(playerState, newStateBeforeAutoDeathSave))
    turnResolver.resolveDeathSave(newStateBeforeAutoDeathSave) else null
    Результат (diceRolls, description, stateChanges) добавляется в ту же TurnMechanics (:978-985).

    12.6 Massive damage¶

    Где: sessions/SessionService.kt:2086-2103. 

    val wasUnconsciousBefore = hp == 0 || "Без сознания" in statuses
hp = (hp - change.amount).coerceAtLeast(0)
if (hp == 0) {
    if ("Без сознания" !in statuses) statuses.add("Без сознания")
    dropConcentration()
    val massiveDeath = change.amount >= state.maxHp          // :2095
    if (massiveDeath) isDead = true                          // :2096
    if (wasUnconsciousBefore && !massiveDeath) {
        deathSuccess = deathSuccess.coerceAtLeast(0)
        deathFail += 2
        if (deathFail >= 3) isDead = true
    }
}
    Сравнение — полный change.amount (не «переполнение» после 0) с state.maxHp.

    12.7 Урон по бессознательному (автокрит)¶

    Где: sessions/SessionService.kt:2087-2102 (фрагмент выше). Флаг wasUnconsciousBefore = hp == 0 || "Без сознания" in statuses (:2088). При wasUnconsciousBefore && !massiveDeath — deathFail += 2.

    12.8 Исцеление с 0 HP¶

    Где: sessions/SessionService.kt:2124-2132. 

    is StateChange.Heal -> if (change.target == StateTarget.PLAYER) {
    val wasUnconscious = hp == 0
    hp = (hp + change.amount).coerceAtMost(state.maxHp)
    if (wasUnconscious && hp > 0) {
        statuses.remove("Без сознания")
        statuses.remove("Стабилен")
        deathSuccess = 0
        deathFail = 0
    }
}
    Условие hp > 0 — при лечении, не поднявшем HP выше 0, сброса нет.

    12.9 Три успеха / стабилизация¶

    Где: sessions/SessionService.kt:2240-2249. 

    is StateChange.DeathSaveSuccess -> {
    deathSuccess += 1
    if (deathSuccess >= 3) {
        statuses.remove("Без сознания")
        if ("Стабилен" !in statuses) statuses.add("Стабилен")
        if (hp == 0) hp = 1
        deathSuccess = 0
        deathFail = 0

}
    Провалы: is StateChange.DeathSaveFail -> { deathFail += 1; if (deathFail >= 3) isDead = true } (:2250-2253). coerce до 3 отсутствует.

    12.11 Checkpoint-механика¶

    Где: rules/GameState.kt:688-699; sessions/SessionService.kt:1418-1420,1424-1433,1498-1503.

    ...
    val checkpointState: CharacterState? = null,   // :699

    Сохранение в участника: it.copy(state = finalState, checkpointState = checkpointToSave) (:1498-1503).     12.12 Восстановление после смерти¶

    Где: rules/DeathRules.kt:23-37; sessions/SessionService.kt:1424-1433. 

    fun resolveDeathRestore(state, checkpoint, permadeath): Pair<CharacterState, Boolean> {
    if (permadeath) return state to false
    val cp = checkpoint ?: state
    return cp.copy(
        hp = (cp.maxHp / 2).coerceAtLeast(1),
        isDead = false,
        deathSaveSuccess = 0,
        deathSaveFail = 0,
        statuses = cp.statuses.filter { it != "Стабилен" },
    ) to true
}

    val (finalState, restoredFromCheckpoint) = if (characterDied) {
    val checkpoint = checkpointToSave ?: participant.checkpointState
    DeathRules.resolveDeathRestore(state = newStateWithDrops, checkpoint = checkpoint, permadeath = profile.mechanics.permadeath)
} else newStateWithDrops to false
    Флаг прокидывается в MechanicsBlock.restoredFromCheckpoint (:1466) и deathImageUrl (:1579).

    12.14 StateChange.CharacterDied¶

    Где: определение GameState.kt:1166; обработчик SessionService.kt:2239 (isDead = true); нарратив :1080-1083. Эмиссия (создание StateChange.CharacterDied) в коде не найдена. Фактическое isDead = true выставляется напрямую: SessionService.kt:2096,2101,2252.

    Открытые вопросы¶

    1. deathSaveFail/deathSaveSuccess инкрементируются без coerce при require(... in 0..3) (GameState.kt:480-481): nat 1 (+2) или автокрит (+2) при текущем значении 2 дают 4 — возможна ли ошибка валидации при state.copy в applyStateChanges, требует уточнения.
    2. nat 20 сбрасывает счётчики только косвенно, через Heal с wasUnconscious = hp == 0; если HP уже > 0, сброса не будет — требует уточнения сценария.
    3. 3 успеха трактуются как «Стабилен» при HP 1 и снятии «Без сознания» (:2242-2245) — отличается от «stable at 0 HP»; требует подтверждения, что это intended.
    4. StateChange.CharacterDied и StateChange.RestoreCheckpoint не эмитятся — требуется подтверждение их статуса (мёртвый код / задел).
    5. Checkpoint сохраняется только на ходах action == "no_roll"; поведение для сессий без таких ходов (checkpoint = null → cp = state) требует уточнения.

    Сводка¶

    • Реализовано: модель deathSaveSuccess/Fail (0..3) и «Без сознания»; авто-спасбросок при падении в 0 HP в том же ходе; замена действий на death save при бессознательности; nat 20 (сознание + 1 HP), nat 1 (2 провала); massive damage; автокрит по бессознательному (+2 провала); исцеление с 0 HP со сбросом счётчиков; стабилизация по Medicine DC 10; 3 успеха/3 провала; checkpoint-восстановление с половиной HP; permadeath HARDCORE.
    • Частично: сброс счётчиков при nat 20 (косвенно); massive damage по полному урону, а не по переполнению; 3 успеха дают HP 1 и сознание; checkpoint только на no_roll; CharacterDied/RestoreCheckpoint не эмитятся; отсутствует coerce счётчиков при require.
    • Отсутствует: эмиссия StateChange.CharacterDied; эмиссия StateChange.RestoreCheckpoint; смерть от exhaustion 6; проверка deathSaveFail/Success на верхнюю границу перед state.copy.
