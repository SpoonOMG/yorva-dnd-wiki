    Фактура из кода¶

    2.7.1 ATTACK ROLL¶

    Где: rules/TurnResolver.kt:1592-1766. 

    val attackMod = when {
    isFinesse -> maxOf(character.effectiveAttributes.strMod, character.effectiveAttributes.dexMod) // :1673
    isRanged  -> character.effectiveAttributes.dexMod                                             // :1674
    else      -> character.effectiveAttributes.strMod                                             // :1675
} + proficiencyBonus(character.level) + character.weaponAttackBonus + fsAttackBonus                // :1676
    - PB начисляется безусловно по уровню (:1676); проверки владения оружием нет (grep proficienc в TurnResolver.kt не даёт ветки оружия). - Преимущество/помеха: врасплох/скрыт/цель даёт преимущество (:1637-1643); hasAdv -> maxOf(dice.d20(), dice.d20()), hasDisadv -> minOf(...) (:1644-1648). - Финальный бросок: applyModifiers(baseTotal, "attack_roll", character) (:1685). - Unarmed fallback: equippedItem?.effectiveDamageDice ?: weapon?.damageDice ?: "1d6" (:1689, повтор :1744); урона 1+STR нет. - Промах nat 1 → «Ошеломлён» (:1670,1704); проверка боезапаса (:1707-1719).

    2.7.2 УРОН¶

    Где: rules/TurnResolver.kt:1695-1724. 

    val damage = if (hit) (damageRoll + damageMod + weaponBonus + fsDamageBonus - damagePenalty)
    .coerceAtLeast(1) else 0                                        // :1702
if (hit && damage > 0) stateChanges += StateChange.Damage(damage, StateTarget.ENEMY) // :1721
    StateChange.Damage создаётся без damageType (:1721, :2697); тип урона оружия не передаётся. Дополнительно: damageBonus экипированного оружия + боевой стиль Дуэлянт (:1700-1701); мультистрельба «три стрел»/«залпом» — расход Стрелы (:1723-1724).

    2.7.3 КРИТИЧЕСКИЕ УДАРЫ¶

    Где: rules/TurnResolver.kt:1649,1687-1694. 

    val crit = attackRoll == 20                                          // :1649
val hit = crit || (!fumble && total >= ac)                           // :1687
val critDoubles = crit && "armor_heavy" !in target.features          // :1691
val damageRoll = if (hit) {
    if (critDoubles) dice.roll(diceTimes * 2, diceSides) else dice.roll(diceTimes, diceSides) // :1693
} else 0
    Крит только nat 20; расширение диапазона (critRange) отсутствует (grep 0). Подавление крита фичей armor_heavy (:1691) — homebrew, подлежит удалению. Savage Attacks / Brutal Critical (доп. кости) отсутствуют (grep Savage/Brutal/critBonusDice — 0). Для заклинания: val crit = roll == 20 (:1833), эффект крита на урон не применяется (урон фиксирован 2d4, :1845).

    2.7.4 СПАСБРОСКИ ОТ ЗАКЛИНАНИЙ¶

    Где: spells/SpellService.kt:153-154. 

    val dc = spell.savingThrow?.dc ?: 13
val save = if (spell.savingThrow != null) SavingThrowResolver(...).resolve...
    DC берётся из spells.json (savingThrow.dc); SpellService не вычисляет DC персонажа по 8 + PB + spellMod. Enemy.spellSaveDc отсутствует (GameState.kt:643-664; grep 0). Функция вычисления DC заклинаний игрока отсутствует (см. Ф3).

    2.7.5 SAVING THROWS¶

    Где: rules/SavingThrowResolver.kt. 

    fun resolvePlayerSave(...): SaveResult { ... }                       // :22-53

    2.7.6 COVER¶

    Где: отсутствует. grep -i cover в rules//sessions/ не даёт боевой механики (найденные совпадения — мир/картинки: WorldCover, coverImage). Механики cover=HALF/THREE_QUARTERS/TOTAL (бонус к AC/DEX-спасброскам) нет.

    2.7.7 FLANKING¶

    Где: отсутствует. Полей/флага engagedByAllies нет (grep 0); позиционирования (isEngaged) в правилах нет.

    2.7.8 MULTIATTACK¶

    Где: rules/TurnResolver.kt:2651-2671 (враг), :1592 (игрок). 

    val legendaryExtra = if ("legendary" in enemy.features) 1 else 0    // :2653
val attackCount = (if ("multiattack" in enemy.features) 2 else 1) + legendaryExtra // :2654
repeat(attackCount) { attackIndex -> ... }                           // :2662
    Мультиатака существует только у врага (по фиче multiattack, ровно 2 атаки) + легендарная атака (:2653). Extra Attack игрока отсутствует: resolveAttack выполняет ровно один бросок атаки (grep ExtraAttack/extraAttack — 0). Агрегации TurnMechanics.merge/enemyHp нет.

    2.7.9 TWO-WEAPON FIGHTING¶

    Где: off_hand — только слот экипировки: CharacterState/EquipmentAnchor (GameState.kt:445), EquipmentAnchorService.kt:73, SessionService.kt:2510. Атаки off-hand как бонусного действия нет; проверки свойства LIGHT нет.

    2.7.10 RANGED IN MELEE¶

    Где: rules/TurnResolver.kt:1658. 

    val isRanged = equippedIsRanged || catalogIsRanged || RANGED_WEAPON_PATTERN.containsMatchIn(actionLower) // :1658
    Дальность влияет на модификатор (:1674) и стиль (:1669), но помехи за дальнобойную атаку в упор нет (позиционирования/isEngaged нет).

    2.7.11 SPELL ATTACKS¶

    Где: rules/TurnResolver.kt:1808-1882. 

    val dc = detectDc(action, defaultDc = 13, profile = profile)         // :1829
val spellMod = castingAttribute.second + proficiencyBonus(character.level) // :1831
val total = roll + spellMod                                          // :1832
val success = crit || (!fumble && total >= dc)                       // :1835
if (success && !isSummon && enemy != null) {
    val damageRoll = dice.roll(2, 4)                                 // :1845
    stateChanges += StateChange.Damage(damageRoll, StateTarget.ENEMY)// :1846
}
    - Атака заклинанием сравнивается с DC, а не с AC цели (:1829,1835) — не по SRD. - Урон атакующего заклинания всегда 2d4 (:1845), не зависит от заклинания; крит (:1833) урон не удваивает. - Скалирование заговоров по уровням (scalingType: DICE/BEAMS/ADDITIONAL) отсутствует (grep 0). - Стоимость — фиксированная SPELL_MANA_COST (:1816); отдельный путь resolveCastSpell (:1890) использует SpellService. - SpellService.resolveDamage бросает спасбросок врага, но не бросок атаки; при savingThrow == null урон наносится без защиты (AUTO-эквивалент).

    2.7.12 RESISTANCE / IMMUNITY¶

    Где: spells/SpellService.kt:167-173. 

    val type = effect.damageType.lowercase()
val dealt = when {
    type in enemy.immunities.map { it.lowercase() } -> 0
    type in enemy.resistances.map { it.lowercase() } -> amount / 2
    else -> amount
}
    - Только у Enemy (GameState.kt:662 resistances, :664 immunities); vulnerabilities нет ни у врага, ни у игрока (grep 0). - Урон оружия создаётся без damageType (:1721), поэтому сопротивления врага к B/P/S к оружейным атакам не применяются. - Для игрока SessionService.applyStateChanges вычитает change.amount без учёта типа (SessionService.kt:2086-2103).

    2.7.13 HP И СМЕРТЬ¶

    Где: sessions/SessionService.kt:2086-2103,2124-2133,2248-2260. 

    is StateChange.Damage -> if (change.target == StateTarget.PLAYER) {
    val wasUnconsciousBefore = hp == 0 || "Без сознания" in statuses     // :2088
    hp = (hp - change.amount).coerceAtLeast(0)                           // :2089
    if (hp == 0) {
        if ("Без сознания" !in statuses) statuses.add("Без сознания")    // :2091
        dropConcentration()                                              // :2093
        val massiveDeath = change.amount >= state.maxHp                  // :2095
        if (massiveDeath) isDead = true                                  // :2096
        if (wasUnconsciousBefore && !massiveDeath) { deathFail += 2; ... } // :2097-2101
    }
    ...
}
is StateChange.DeathSaveFail -> { deathFail += 1; if (deathFail >= 3) isDead = true } // :2250-2252
is StateChange.Stabilized -> {
    statuses.remove("Без сознания"); statuses.add("Стабилен")
    if (hp == 0) hp = 1; deathSuccess = 0; deathFail = 0                 // :2254-2260

    - Healing при 0: is StateChange.Heal снимает «Без сознания»/«Стабилен» (:2124-2132), т.е. поднимает с 0 с приоритетом над стабильностью. - Стабилизация: StateChange.Stabilized (GameState.kt:1171) эмитится из stabilize_ally (TurnResolver.kt:1110-1111); проверки Medicine DC 10 нет. - Концентрация при уроне: спасбросок CON DC maxOf(10, amount/2) (:2106-2114).

    2.7.14 ИНИЦИАТИВА¶

    Где: rules/TurnResolver.kt:2713-2799. - Персональная (:2713) и групповая/списком (:2727); групповая — один d20 на архетип (:2759). - Сюрприз — бросок с помехой (:2734,2760), участники в surprisedParticipants (:2751-2752,2774,2783). - Легендарное существо — доп. атака (:2653). - CombatState.INITIATIVE_COMPARATOR (:2777); вставка нового врага insertIntoInitiative (:2805). - Пропуск первого хода «врасплох» для игрока: SessionService.kt:853 (проверка) и :1362 (снятие флага).

    2.7.15 WHITELIST / DSL¶

    Где: rules/ActionWhitelist.kt, rules/ActionParser.kt, rules/intent/ActionIntent.kt. 

    "MANEUVER" -> ActionRequest(ActionType.CHECK, action, lower, dslId=dslId, dslTarget=target) // ActionParser.kt:555
    MANEUVER есть в whitelist (ActionWhitelist.kt:92,140,143), но мапится на общий CHECK без параметров (cover/flank/engage). ActionIntent существует (rules/intent/ActionIntent.kt), но боевых параметров MANEUVER (cover=…, engage) не несёт.

    2.7.16 СПОСОБНОСТИ КЛАССОВ¶

    Где: classes/ClassFeatureHelper.kt:22,42,75; rules/TurnResolver.kt:244-271. 

    val featureCost = ClassFeatureHelper.detectFeature(actionLowerEarly, character, classRegistry) // :244
val featureError = featureCost?.let { ClassFeatureHelper.canAfford(it, character.actionEconomy, character.classResources) } // :245
if (featureCost != null && actionEconomyRegistry?.grantsExtraAction(featureCost.resourceId) == true) { ... GrantExtraAction(1) } // :257-271
    - detectFeature ищет активируемые фичи по ключевому слову имени (ClassFeatureHelper.kt:25-36). - canAfford проверяет экономию действий и ресурсы (:42-50); spendCost формирует SpendAction/SpendBonusAction/SpendReaction + SpendClassResource (:75-85). - Action Surge выдаёт доп. действие (TurnResolver.kt:256-271). - Эффекты фич (Rage damage, Divine Smite, Ki/Flurry, Wild Shape) не резолвятся: FeatureRegistry/resolveFeatureAction отсутствуют (grep 0). rageDamageBonus/rage resist/martialArtsDie/sneakAttack отсутствуют (grep 0).

    2.7.17 БОЕВЫЕ СОСТОЯНИЯ¶

    Где: sessions/SessionService.kt:2134-2147. 

    is StateChange.ApplyStatus -> { if (change.status !in statuses) statuses.add(change.status)

    2.7.18 XP ЗА БОЙ¶

    Где: TurnResolver.kt:1728 (оружие), :1849 (заклинание). 

    if (defeated) stateChanges += StateChange.GainXp(xpForEnemy(updatedEnemy)) // :1728, :1849
    XP начисляется в TurnMechanics до применения; отдельный per-object/per-NPC XP (xpForEnemy).

    2.7.19 ЛУТ ПОСЛЕ БОЯ¶

    Где: TurnResolver.kt:1765,1881 (withLoot(enemy.takeIf { defeated })), :1268 (rollLootDrops).

    Ф0–Ф3 (фундамент)¶

    • Ф0: enum DamageType отсутствует. Тип урона — String: SpellEffect.Damage.damageType (spells/Spell.kt:72), StateChange.Damage.damageType: String? (GameState.kt:1118), Enemy.resistances/immunities: List<String> (GameState.kt:662,664).
    • Ф1: DamageResolver отсутствует. У врага ÷2/0 вручную (SpellService.kt:167-173), vulnerability не применяется; для игрока тип урона не учитывается (SessionService.kt:2086-2103).
    • Ф2: поля resolution нет ни в Spell (Spell.kt:9-23), ни в spells.json (0 совпадений, 90 записей). Ветвление — по savingThrow != null (SpellService.kt:153).
    • Ф3: SpellcastingStats/spellSaveDc/spellAttackBonus отсутствуют. CharacterClass.spellcastingAbility есть (CharacterClass.kt:13, ClassRegistry.kt:120), но способность заклинателя определяется regex detectCastingAttribute (TurnResolver.kt:2976-2983, default INT); spell.castingAbility нет (grep 0).

    Таблицы данных¶

    • spells.json: 90 записей; 11 типов урона (acid, cold, fire, force, lightning, necrotic, piercing, poison, psychic, radiant, thunder); полей resolution/castingAbility — 0.
    • SpellRegistry парсит damageType как String; resolution не читается.

    Открытые вопросы¶

    1. Атака заклинанием в resolveSpellOrSummon сравнивается с DC, а не с AC цели (TurnResolver.kt:1829,1835) — критерий приемлемости/переписывания требует уточнения.
    2. Урон боевого заклинания фиксирован 2d4 (:1845) — откуда берётся 2d4 и нужно ли использовать spell.damage, требует уточнения.
    3. StateChange.Damage для врага не несёт damageType (:1721) — как быть с сопротивлениями врага к оружию, требует уточнения.
    4. Подавление крита фичей armor_heavy (:1691) — homebrew, оставить/убрать требует подтверждения (запланировано в 2.7.X).
    5. off_hand как слот экипировки (GameState.kt:445) — намеренно ли только экипировка без бонус-атаки, требует уточнения.

    Сводка¶

    • Реализовано: атака оружием (преимущество/помеха, крит nat 20, боевые стили, боезапас, штрафы тяжёлого оружия); спасброски игрока/врага (SavingThrowResolver); сюрприз (бросок с помехой, пропуск хода, преимущество первой атаки); инициатива (групповая, легендарные, вставка врага); смерть (3 провала, массивный урон, стабилизация, heal с 0); боевые состояния с длительностями; XP и лут за победу; class resources + activation-гейтинг фич; Action Surge; мультиатака врага.
    • Частично: ATTACK ROLL (нет владения оружием, unarmed 1d6); УРОН (нет типа урона, off-hand, стаков); КРИТЫ (нет critRange/Savage/Brutal, homebrew armor_heavy); spell save DC (Enemy.spellSaveDc/PC-DC отсутствуют); SPELL ATTACKS (vs DC, фикс. 2d4, нет cantrip scaling); RESISTANCE/IMMUNITY (только Enemy, без vulnerability и без типа у оружия); HP/смерть (нет Medicine DC 10); WHITELIST (MANEUVER не параметрический); СПОСОБНОСТИ КЛАССОВ (гейтинг есть, эффекты не резолвятся); Ф3 (spellcastingAbility по regex).
    • Отсутствует: enum DamageType (Ф0); DamageResolver (Ф1); SpellResolution (Ф2); SpellcastingStats (Ф3); cover, flanking, two-weapon, ranged-in-melee; Extra Attack и sneak attack игрока; vulnerabilities; critRange; cantrip scaling; lair actions; damageReduction; engagedByAllies/isEngaged; FeatureRegistry/resolveFeatureAction; Martial Arts die; rage damage/resistance; Divine Smite; Ki/Flurry эффекты.
