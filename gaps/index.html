    docs/gaps.md — Реестр открытых gap'ов¶

    Живой реестр дефектов и отклонений от канона/ожидания (аналог ADR-0011, но для gap'ов, а не архитектурных решений).

    Overview¶

    • Что такое gap: отклонение от канона/ожидания — НЕ баг в только что написанном коде.
    • Как пополняется: по мере обнаружения (в бою, в тестах, при debug, из аудитов/ADR).
    • Owner: Оркестратор ведёт реестр; закрытие фиксирует исполняющая роль.
    • Статусы: Open / In-progress / Fixed / Deferred / Frozen.
    • Обновление при закрытии: Status → Fixed + дата закрытия.

    Закрыто 2026-09-24 (2.9)¶

    • G-029 — spell damage применяется к enemy (confirmed live).
    • G-026 — UI HP врага синхронизирован (confirmed live).
    • G-027 — UI HP игрока синхронизирован (confirmed live).
    • G-033 — reaction «Щит» не восстанавливает HP (confirmed live).
    • G-010 — debug-endpoint state ≠ checkpointState (ранее).

    Закрыто 2026-09-24 (2.9a — frontend UI sync)¶

    • G-020 — UI слоты заклинаний (виджет «Ур.N — X/Y»).
    • G-034 — UI эффективный AC (base + activeModifiers[ac]).
    • G-035 — reaction gate по hp>0 && !UNCONSCIOUS.

    Закрыто 2026-09-24 (G-035 hardening + G-040 backend gate)¶

    • G-035 — frontend half: сброс reactionPrompt (hardening, ff4b1b1).
    • G-040 — backend half: availableReactions gate по hp/UNCONSCIOUS (8810c3f).

    Priority levels¶

    Приоритет Значение
    CRITICAL Блокирует текущую и следующую фазу (старт следующей фазы запрещён)
    H Блокирует текущую работу
    M Существенно влияет, но не блокирует
    L Косметика / низкий приоритет

    Связка G-026 / G-029 — resolved (2.9, 2026-09-24)¶

    Сквозная проблема «spell damage не доходит до enemy + UI не показывает HP» закрыта:

    • G-029 — TurnResolver.resolveCastSpell применяет Damage(ENEMY) → Enemy.copy. Fixed + confirmed live.
    • G-026 — UI HP врага синхронизирован со state. Fixed + confirmed live.
    • G-027 — UI HP игрока синхронизирован со state. Fixed + confirmed live.
    • G-033 — reaction «Щит» больше не восстанавливает HP (только AC+5). Fixed + confirmed live.

    ФАЗА 3 больше не блокирована этой связкой.

    Связка G-035 / G-040 — resolved (2026-09-24)¶

    Реакция «Щит» предлагалась мёртвому/бессознательному персонажу — две половины одного бага:

    • G-035 (frontend) — сброс reactionPrompt на новый ход и на load (stale state держал модал). Fixed: ff4b1b1.
    • G-040 (backend) — availableReactions() гейтился только по hasReaction(), не по hp/UNCONSCIOUS; предлагал «Щит» при hp=0. Fixed: 8810c3f.

    Design notes¶

    • state.effectiveAc помечено @JsonIgnore в backend — frontend обязан считать derived AC сам. Правильно, оставляем.

    Правила ведения¶

    • Гэп = отклонение от канона/ожидания, не баг в только что написанном.
    • Приоритет H = блокирует текущую работу.
    • Поле «Фаза» = где логично чинить.
    • При закрытии: Status → Fixed + дата закрытия.
