    Финальный чеклист — все исправления без потерь (14 слоёв)¶

    Источник правды: docs/dialog-fixes-todo.md + 5 whitelist/*.yaml + dsl-templates.yml 25 шаблонов Архитектура: хард-оверрайд(2-3) → LLM 25 → Валидатор(target) → Whitelist(YAML) → Движок → LLM-нарратив + loot/XP/состояния отдельные слои

    1. Откуда intent → whitelist¶

    • Источник: хард-оверрайд(2-3 очевидных) → LLM 25 → regex-fallback
    • Whitelist чекает любой dslId после трёх
    • Если LLM вернула id не из whitelist/*.yaml → canExecute=false → NO_ROLL + лог whitelist blocked {dslId, action:"помогаю"} для промпта
    • Без второго LLM вызова (дорого)

    2. 25 шаблонов vs 150 команд¶

    • 25 — шаблоны с параметром, 150 — их конкретики
    • CHECK{skill} 1→16 CHECK_*, ATTACK{type} 1→7 ATTACK_*, CAMP_REST/CAMP_FIRE 3→13
    • LLM видит 25 (~320 токенов), whitelist хранит 150 для точных CHECK_PERCEPTION false / INVESTIGATION true
    • Маппинг при проверке: CHECK{investigation} → CHECK_INVESTIGATION, ATTACK{melee} → ATTACK_MELEE
    • Файл: dsl-templates.yml 25 + whitelist/*.yaml 150 — оба, 25 интерфейс

    3. Хард-оверрайд vs LLM — конфликт (вариант C выбран)¶

    • Проблема: надеваю на него наручники → EQUIP (должен GRAPPLE), разведи огонь в его глазах → CAMP (должен SOCIAL), прячусь за спину союзника → HIDE (должен DEFEND)
    • Фикс C минимальный 2-3 очевидных + LLM + whitelist: 
      hard_override:
  - "надеваю\\s+(молот|меч|шлем|броню|кольчугу|плащ|сапоги|перчатки)\\b" + SELF + itemInInventory → EQUIP
  - "снимаю\\s+(молот|меч|шлем...)" + SELF → UNEQUIP
  - "прячусь$|прячусь\\s+в\\s+(тени|укрытии)" + SELF → HIDE
      Остальное → LLM. Если оверрайд сработал но whitelist режет → откат в LLM.

    4. Валидатор vs Whitelist — дублирование (ATTACK без врага)¶

    • Оба резали ATTACK без врага
    • Решение: Whitelist первичен (YAML — дизайн), Validator — тонкая targetType + whitelist.canExecute
    • Убрать дубли hasEnemy/hasSpellSlots из DslValidator, оставить targetType и ALLOW NO_ROLL

    5. NO_ROLL — что дальше¶

    • NO_ROLL — финал движка (нет HP/XP), но narrator.narrate всё равно идёт → игрок получает ответ без кубика
    • Проблема социал→CAST→NO_ROLL = фрустрация Ничего не произошло
    • Гибрид C: CAST без слотов + без "кастую" → SOCIAL без LLM (контекст), CAST со слотами → NO_ROLL + лог
    • Логировать все whitelist blocked

    6. XP — кто начисляет (per-location, не per-rest)¶

    • Слой XP только движок (GainXp), LLM описывает
    • Сейчас: hide 15, check 25-75, социал 25, открыл/взломал 25, убил 50-300, задание 100-300, NO_ROLL 0 + xpTriggers разово
    • Фикс per-location/per-object/per-NPC, не per-rest (иначе фарм отдыхом):
    • hide_success → !scene.hasHidden, search_room_01 → location:room_01
    • Убил → !enemy.defeated, задание → !quest.completed, сундук → !object.isOpened, социал → !npc.isPersuaded
    • Баланс: исследование 15→50 если первое, milestone +50 за сцену, иначе бой выгоднее
    • xpTriggers: Set<location/object/npc/enemy> сбрасывать по флагу объекта, не по rest
    • Потеряно-добавить: баланс 50/milestone + флаги isOpened/isPicked/isDisarmed/defeated/completed/isPersuaded

    7. Состояния — кто накладывает¶

    • Только движок (ApplyStatus + statusDurations + tickDurations), XP не даётся, LLM описывает
    • Сейчас: isIncapacitated блокирует, Скрыт→advantage, Уклонение→disadvantage, tick в конце
    • Дыры: 7.1 только isIncapacitated — нет Restrained/Grappled/Prone→нет движения, Blinded/Deafened→нет восприятия; 7.2 whitelist/validator не проверяют statuses и не сообщают Парализован; 7.3 duration=1 без saveEnds CON DC12
    • Фикс: canMove/canAttack/canSpeak по statuses, statuses→whitelist + сообщение причины, tick в конце + saveEnds

    8. Реакции¶

    • Триггер движка, не intent; сейчас только OPPORTUNITY_ATTACK
    • Дыры: 8.1 выбор игрока модалка использовать реакцию?; 8.2 16+ реакций (Sentinel, Mage Slayer, Polearm Master, Defensive Duelist, Riposte, Parry, Uncanny Dodge, Evasion, Slow Fall, Deflect Missiles, Absorb Elements, Feather Fall, Shield, Counterspell, Hellish Rebuke); 8.3 триггеры ENEMY_LEAVES/PLAYER_TAKES_DAMAGE/ENEMY_CASTS/PLAYER_FALLS → реакции; 8.4 reactionUsedThisRound 1/раунд
    • Фикс: reaction_triggers.yml + whitelist REACTION: hasReaction && !reactionUsedThisRound + модалка
    • Потеряно-добавить: список 16+ + модалка Да/Нет

    9. Множественные действия¶

    • Составные Атакую и отступаю сейчас 1 intent
    • Фикс: LLM сплитит ["Атакую","отступаю"] → whitelist + actionEconomy 1 Action+1 Bonus+Move
    • Дыры: 9.1 порядок MOVE→ATTACK ok, ATTACK→DISENGAGE нет — последовательно, второе блокируется; 9.2 тип в whitelist (HIDE у плута Bonus); 9.3 остаток movementUsed+planned>total; 9.4 реакции вне хода; 9.5 Action Surge extraAction
    • ATTACK+DISENGAGE 2 Action → NO_ROLL выбери одно
    • Потеряно-добавить: action_economy.yml классификация + последовательная блокировка второго

    10. Концентрация¶

    • Только движок (concentrationSpell + activeModifiers), новый каст сносит старый
    • Дыры: 10.1 DC = max(10, dmg/2) не 10; 10.2 auto-drop при Incapacitated/Unconscious/Paralyzed/Stunned/Petrified; 10.3 DISMISS_SPELL добровольно; 10.4 урон окружения тоже триггерит; 10.5 множественные per source save
    • Фикс: DC = max(10, dmg/2), if Incapacitated→drop, DISMISS_SPELL, onDamage(any)→save, per source

    11. Нарратив vs результат¶

    • Результат известен движку, LLM должна промах→промахнулся
    • Дыры: 11.1 не попал ловит попал; 11.2 patch ломает смысл; 11.3 retry 1 + fallback MISS→промахнулся; 11.4 флейвор промах но отступил не ошибка; 11.5 Structured Output {"narrative":..., "hits":false} надёжней regex
    • Фикс: retry 1 + fallback шаблон, Structured Output если GigaChat JSON, гибкая проверка только убил/попал vs промах

    12. Смерть и спасброски¶

    • Только движок (HP 0→Без сознания, 3 успеха→Стабилен, 3 провала→CharacterDied/RestoreCheckpoint 50%)
    • Дыры: 12.1 auto DEATH_SAVE каждый ход без текста; 12.2 20→1 HP / 1→2 провала; 12.3 урон по бессознательному автокрит +2, dmg>maxHp→мгновенно; 12.4 heal→1 HP, stabilize→без сознания; 12.5 RestoreCheckpoint permadeath/keep_xp; 12.6 massive damage
    • Фикс: auto в начале хода, 20/1 криты, damage>maxHp→isDead
    • Потеряно-добавить: RestoreCheckpoint чётко permadeath/keep_xp/keep_inventory/location + урон по бессознательному

    13. Инициатива¶

    • Только движок (d20+Лов vs d20+Dex, сортировка), LLM описывает
    • Сейчас игрок→applyEnemyTurn без очереди
    • Дыры: 13.1 один раз за бой, новый враг вставляется; 13.2 surprise пропуск; 13.3 0 HP вне очереди; 13.4 групповая один/индивидуально; 13.5 легендарные вне хода; 13.6 сброс при выходе → новая
    • Фикс: rollInitiative() при enemyAppeared + combatStarted, surprise failedPerception
    • Потеряно-добавить: group_roll флаг + сброс combatEnded && combatRestarted + бессознательный вне очереди

    14. Отдых¶

    • Только движок (1ч 1 Hit Dice d6-d12, 8ч HP100% ½ Hit Dice spellSlots), LLM описывает
    • Сейчас: d8 всегда, игрок не выбирает 1..N, длинный снимает Poisoned (не канон), short<2 хаус-рул, нет прерывания/24ч
    • Дыры: 14.1 d6-d12 по классу; 14.2 выбор 1..N HD heal=roll(NdX)+CON*N; 14.3 длинный -1 Exhaustion не Poisoned; 14.4 лимит 2/день не канон; 14.5 прерывание ≥1ч сброс; 14.6 24ч окно lastLongRest
    • Фикс: hitDie по классу, shortRest(toSpend), longRest→Exhaustion-1, onInterrupt(60), 24h флаг
    • Потеряно-добавить: longRest только -1 Exhaustion, не Poisoned + lastLongRest timestamp
