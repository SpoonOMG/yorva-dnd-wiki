    План внедрения: LLM-safe intent architecture¶

    Документ предназначен для передачи ИИ-агенту-разработчику. Все решения зафиксированы. Агент не вносит изменений по своему усмотрению. При любом расхождении с фактами — стоп и отчёт.

    0. Общие правила для агента¶

    0.1. Read before write¶

    Перед изменением любого файла — прочитать его целиком. Не полагаться на номера строк из этого документа как на абсолютные: они ориентировочные. Использовать их как подсказку, но находить фактическое место по имени класса/метода/поля.

    0.2. Не додумывать¶

    • Если файл, класс, метод или поле, упомянутые в плане, не найдены — остановиться, вывести отчёт, не продолжать.
    • Если сигнатура метода не совпадает с ожидаемой — остановиться, вывести отчёт.
    • Если тест падает и его причина не описана в плане — остановиться, вывести отчёт.

    0.3. Каждый этап — атомарный¶

    • Один этап = один коммит (если используется git).
    • После каждого этапа: build и test зелёные.
    • После каждого этапа — отчёт по форме из §0.5.
    • Не переходить к следующему этапу, пока текущий не принят.

    0.4. Что запрещено делать без явного указания¶

    • Не удалять SemanticActionNormalizer, SemanticDictionary, ActionWhitelist, dsl-templates.yml, semantic-dictionary.yml.
    • Не менять TurnResolver.dispatch (кроме добавления новых when-веток, если требуется компилятором).
    • Не менять applyStateChanges.
    • Не менять порядок гейтов в ActionParser до этапа 5.
    • Не рефакторить код «заодно».
    • Не менять формат TurnResponse, MechanicsBlock, CharacterState, Enemy, CombatState.
    • Не менять публичные сигнатуры существующих методов, кроме случаев, явно описанных в этапе.
    • Не удалять существующие тесты. Только добавлять.

    4.5.5. IntentParser.kt: 

    package com.yorva.rules.intent

import com.fasterxml.jackson.databind.DeserializationFeature
import com.fasterxml.jackson.databind.ObjectMapper
import com.fasterxml.jackson.module.kotlin.registerKotlinModule
import org.springframework.stereotype.Component

@Component
class IntentParser {
    private val mapper = ObjectMapper()
        .registerKotlinModule()
        .configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false)

    fun parse(raw: String): Intent? {
        val json = extractJsonObject(raw) ?: return null
        return try {
            mapper.readValue(json, Intent::class.java)
        } catch (_: Exception) {
            null
        }
    }

    private fun extractJsonObject(raw: String): String? {
        val start = raw.indexOf('{')
        val end = raw.lastIndexOf('}')
        if (start < 0 || end <= start) return null
        return raw.substring(start, end + 1)
    }
}

    Примечание: FAIL_ON_UNKNOWN_PROPERTIES = false — чтобы не падать на лишних полях от LLM. Но валидация ниже отсекает смысловой мусор.

import org.springframework.stereotype.Component

@Component
class StateContextBuilder {

    fun build(
        character: CharacterContext?,
        enemy: EnemyContext?,
        sceneType: String,
        recentActions: List<String>
    ): String {
        val sb = StringBuilder()
        sb.appendLine("SCENE: $sceneType")
        character?.let {
            sb.appendLine("PLAYER: hp=${it.hp}/${it.maxHp}, ac=${it.ac}")
            sb.appendLine("ECONOMY: action=${it.actionUsed}, bonus=${it.bonusActionUsed}, reaction=${it.reactionUsed}")
            if (it.spellSlots.isNotEmpty()) {
                sb.appendLine("SPELL_SLOTS: ${it.spellSlots.entries.joinToString { "${it.key}:${it.value}" }}")
            }
            if (it.weapons.isNotEmpty()) {
                sb.appendLine("WEAPONS: ${it.weapons.joinToString()}")
            }
            if (it.consumables.isNotEmpty()) {
                sb.appendLine("CONSUMABLES: ${it.consumables.joinToString()}")
            }
            if (it.spellsKnown.isNotEmpty()) {
                sb.appendLine("SPELLS_KNOWN: ${it.spellsKnown.joinToString()}")
            }
        }
        enemy?.let {
            sb.appendLine("ENEMIES: id=${it.id}, name=${it.name}, hp=${it.hp}/${it.maxHp}")
            if (it.statuses.isNotEmpty()) sb.appendLine("  statuses: ${it.statuses.joinToString()}")
        }
        if (recentActions.isNotEmpty()) {
            sb.appendLine("RECENT: ${recentActions.joinToString(" | ")}")
        }
        return sb.toString()
    }
}
